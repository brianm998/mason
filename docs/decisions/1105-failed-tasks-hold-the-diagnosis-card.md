# 1105: a failed task's diagnosis is answered like any decision card

A diagnosis could only be applied (its recommendation) or dismissed, so the owner could not pick another option, say something else, or add a remark. Decision: while the failure it speaks of lasts, a pending diagnosis' card is the task's card and goes through the existing answer path; the engine gets no new state or event, because the card is read from the diagnosis row. The owner-only and stale-hash checks are the same ones, with the diagnosis id in the hash. Every answer may carry `context`, stored after the label `Owner's context:` and never parsed for an option. This changes a trust file (`attention.rs`): an answer can now act on a failed task (retry, explore, close, cancel), all of which the owner could already do, and no one else can answer.
