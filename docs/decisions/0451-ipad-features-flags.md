# 0451: The iPad differences are platform flags in the environment, not compile-time branches

`PlatformFeatures` (`agentSessions`, `graphEditing`) travels in the SwiftUI environment from `RootView(model:features:)`, so one `RootView` serves the Mac and the iPad and the offscreen tests can render and assert either. The controls are removed from the view tree when a flag is off, never disabled. The iPad text scale default (0.9) is a `MonitorModel` init argument used only when no scale is stored, so a user's choice always wins and the iPhone keeps 1.0. Touch hit areas are padding (a minimum frame plus `contentShape`), not larger drawings, and are a no-op on the Mac. Rejected: `#if os(iOS)` for the differences (the Mac build could not test them) and a separate iPad root (it would drift from the Mac layout the owner wants matched).
