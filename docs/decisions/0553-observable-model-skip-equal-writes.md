# 0553: observe the Swift model with @Observable and skip equal writes

`ObservableObject` has one change signal for the whole object and `@Published` fires on every assignment, so every view redrew on every message. We moved the model to the Observation framework (macOS 14 / iOS 17, already the minimum), where a body is re-run only for the properties it read. Observation also notifies on equal writes, so `apply` compares before assigning. Not chosen: per-view `Equatable` wrappers only (they leave the model-wide signal and the 3 s redraw from announce results), and splitting the model into several `ObservableObject`s (a larger API change). Other small `ObservableObject`s (`RemoteSession`, `PairingModel`, `SharedTick`, `PushRegistrar`) stay as they are: they are not the cost.
