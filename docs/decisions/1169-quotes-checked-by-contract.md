# 1169: the contract checks the quote

A finding or diagnosis that cannot quote the evidence it rests on is refused, in the same session, with where the contract looked. The match is lenient about whitespace, tool line numbers and diff markers but strict about the words, so an invented line cannot pass. Quotes are required on minor findings too, so every finding is checkable. Diagnosis searches the failure, task text, plan, history, test logs and branch diff.
