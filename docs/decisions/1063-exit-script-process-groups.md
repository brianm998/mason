# 1063: each exit script runs in its own process group

The runner pipes each script through `tee`, which waits until every holder of the pipe has gone: the script, any child it left behind, and the fallback watcher's `sleep` (decision 1068). So the runner starts each script in its own process group (`set -m`) and, when the script's own process ends (pass, fail or over the limit), sends the group TERM and then KILL. A signal to the runner is passed on to that group. A child that makes a group or session of its own (a step host) is not covered. The watcher's stdio also goes to /dev/null. We did not lower the limit: the repeat scripts need it. The macOS job limit matches the ubuntu job's 90 minutes, which replaces the 60 minutes that 1068 kept.
