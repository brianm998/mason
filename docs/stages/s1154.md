# s1154: the command-guard test passes on Windows

Summary: the adapter's command-guard test now builds its expected hook path per platform, so it passes on Windows.

## Cause

`write_settings` joins `mason` onto the MCP bridge's directory with `Path`, which uses a backslash on Windows. The test hard-coded `'/bin/mason{EXE_SUFFIX}'` with a forward slash.

## Change

Only the expected prefix in `every_session_is_given_the_command_guard`. It still requires the quoted path, `hook guard ||` and the `exit 2` refusal. The production command is unchanged.
