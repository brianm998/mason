# s1220: a pool wait is not stuck:task

Summary: a step whose lease waits for a GitHub runner pool unit no longer raises stuck:task; overloaded:slots and stuck:wait judge it.

## Cause

A landing queued behind the gha pool has no step history, so the stuck:task limit is the 30 min floor, and it posts no progress. `crates/core/src/health.rs` judged it stuck while the daemon was only waiting on the pool.

## Change

`TaskFact.pool_wait`, filled from `remote_runs::pool_waiting`, and `judge` skips stuck:task when it is set. See decision 1210.
