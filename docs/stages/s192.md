# s192: `mason service install|uninstall|status`

Summary: `mason service install|uninstall|status` runs `masond --managed` under launchd (macOS) or a systemd user unit (Linux), with `--print`, a refusal to overwrite a foreign unit, and a doctor check that recognises the unit.

**What.** `crates/cli/src/service.rs`: unit generation (`plist`, `systemd_unit`), one install/uninstall function per platform (the seam for a Windows service), a `Runner` trait so tests never call `launchctl`/`systemctl`. Units carry a marker comment; install without `--force` and uninstall touch only units carrying it. `status` shows installed/ours/loaded/running and the pid from `daemon.json` (checked alive).

**Tests.** Unit tests with a temp HOME and a fake runner: plist/unit contents, command sequences, refuse-to-overwrite, reinstall, uninstall, status.

**Not verified.** Not run against the owner's real launchd agent or a real systemd; only `--print` and the unit tests were run. Linux paths are covered by tests with a fake runner only.
