# s494: the Compose tests can load Skia's native library

Summary: The Compose app's test JVM now allows native access, so the Skia-backed MascotTest and TopBarTest tests stop failing with UnsatisfiedLinkError.

What changed
- `clients/compose/app/build.gradle.kts`: `tasks.test` passes `--enable-native-access=ALL-UNNAMED`, as the desktop run does.
- No assertion and no production code changed; `Mascot.bitmap()` still catches only `Exception`.

Diagnosis: the failure is an `UnsatisfiedLinkError` from the Skia (skiko) native library used by `loadImageBitmap`. The step that planned this had no way to run Gradle, so the exact library name and linker text were not read from the XML report; the run_check result for this change is the confirmation. If the error persists, the cause is not a JVM argument and needs a follow-up.
