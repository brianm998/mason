# s903: a red suite no longer fails the mason-run GitHub run

Summary: The `mason-run` workflow ends green when result.json holds a verdict, red or not, and fails only when no result.json exists, so red checks stop sending failure emails while MASON still reads the code from the artifact.

The last step (`exit`) used to exit with the suite's code. MASON reads the verdict from the artifact (`remote.rs` `read_artifact`), not the conclusion, so the step now writes `verdict: code C, phase P, run Ns` to the step summary and exits 0. A missing or non-numeric `code` exits 1. A run cut off by `timeout-minutes` stays failed. No change to `remote.rs` or `github.rs`. `.github/workflows/**` is protected and needs owner approval.
