# s438: the monitor update test parses the request body

Summary: The monitor-button update test now checks `kind`, `own_version` and `own_path` of the parsed request body instead of an exact string that predated s326.

## What changed

`testTheMonitorButtonFollowsTheBuildAndInstallsItOnce` compared the body with `{"kind":"swift"}`; the model has sent `own_path` and `own_version` since s326. The test decodes the JSON and asserts the three keys. No production code changed.
