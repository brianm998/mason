# s132: the Mac monitor icon is a rounded rectangle on Apple's grid

Summary: The Mac and Compose-on-macOS app icon is now a shaped variant (824 px rounded rectangle with a shadow on a transparent 1024 canvas) made by a committed Swift script, so it has rounded corners and the size of the icons around it.

- `scripts/gen-app-icon-macos.swift` writes `Art/brand/app_icon_macos.png`; listed in `clients/mascot.toml`.
- `bundle-monitor.sh` builds `MASON.icns` from it; `App.swift` uses `Mascot.macAppIconData()`; Compose `appIcon()` uses it on macOS.
- Tests: Swift (size, alpha, transparent corners and (50, 512), opaque centre, iOS icon opaque) and Compose (transparent corner, opaque centre); manifest count 110 to 111.
- Exit test: `scripts/exit/s132.sh`.
- Decision: 0118.

Not verified: the shape was only looked at as a PNG, not in the Dock; the manifests were edited by hand to match `conformance mascot --write` (its `--check` is run by the test suite). I did not bundle MASON.app, put it in the Dock beside Finder or Safari, or take a screenshot, so the rounded look and matching size are not confirmed by eye. The corner curve is an approximation of Apple's. Compose tests were not run by me; Swift tests are run only through the check queue.
