# s76: Monitors show each running LLM session's tokens live

Summary: A running agent step's cell now carries the tokens its LLM session has used so far (Claude from `--include-partial-messages`, Codex at turn end), summed over resumed and retried invocations, and both monitors show it as "12.2k in, 988 out" with the full figures on the task page.

## Why

Tokens appeared only after an attempt ended, so a develop step that ran for hours showed no figure.

## What changed

- `claude.rs`: `--include-partial-messages`; `ParseState` keeps a per-invocation tally (message_start opens, message_delta replaces, `result` replaces the whole) and hands the latest over with `take_live`. `assistant` events do not touch it. `AgentEvent::Tokens` is unchanged.
- `adapter-api`: `SessionSpec::on_tokens` (`TokensSink`), reported per stream by `hosted::Feed` and the direct reader; `codex.rs` reports at `turn.completed`.
- `core::progress`: `Progress::output` judges whole lines and skips `stream_event` ones; one `Tokens` tally per stream, summed by `token_total`; `report_tokens` is `Change::Output`, so the per-run throttle limits it to a push a second.
- `store`: additive `step_progress.tokens` column (migration 21), written by `put_progress`, read by `progress_rows`.
- `daemon`: `jobs.rs` wires `on_tokens` (cost only for an `api` account); `cell_of` fills `ProgressCell.tokens` (proto field 21, a `TokenLine`); `GET /tasks/{id}` progress JSON has `tokens`; the demo's running steps have some.
- Monitors (Swift, Compose): compact text on `ProgressLine`, full figures on `ProgressDetail`, `progressTexts` includes both; Rust `progress_text` and conformance have the same rule; `clients/features.toml` has `live-tokens`.
- `fake-claude` writes `stream_event` lines when given the flag.

## Tests

`claude` (fixture live figures end at the result, repeated assistant events change nothing, plain stream has one live figure), `codex` (live only at `turn.completed`), `core::progress` (stream events not counted at every cut, mark inside a line, tokens summed and replayed), `progress_text`, `store` round trip, `daemon/tests/live_tokens.rs` (cell gains tokens mid-step, restart mid-step does not double, output counts, cost by account), Swift and Compose tests.
