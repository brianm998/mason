# s1074: macOS exit-script watcher no longer holds the output pipe

Summary: The no-timeout(1) watcher in run-exit-scripts.sh redirects its stdio and kills its sleep, so macOS exit-script shards stop waiting out the whole script limit; the macOS job limit is 90 minutes.

## Cause

On macOS the watcher subshell's `sleep $limit` was orphaned when the watcher was killed and kept the `| tee` pipe open, so every script took the full limit (s06 read 3601 s) and the job was cancelled at 60 minutes.

## Change

Watcher stdio goes to /dev/null, its child is killed first, `exit-scripts-macos` gets timeout-minutes 90, and `scripts/exit/s1074.sh` covers the path without timeout(1).
