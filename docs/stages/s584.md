# s584: the smoke list named a crate that no longer exists

Summary: The smoke list named the crate `mason`, which is now `mason-pipeline`, so every cargo-workspace run failed before a test ran; it now names `mason-pipeline`, and an exit script checks each `-p` name in the smoke list against the workspace.

**Cause.** The crate in `crates/cli` is the package `mason-pipeline` (`crates/cli/Cargo.toml:3`), but `.mason/smoke-tests.txt:10` still said `-p mason --test init`. The list is passed to the build tool as written, so it failed with "package ID specification `mason` did not match any packages".

**Change.** Line 10 now reads `-p mason-pipeline --test init`. `scripts/exit/s584.sh` checks every `-p` name against the workspace metadata and builds the init target. `.mason/**` is protected, so the smoke-list edit needs owner approval.
