# s1082: count only unplanned daemon restarts

Summary: daemon:restarts counts only unplanned starts, so a takeover from `mason update` no longer counts as a restart.

## Change

`take_over` writes a `planned` health row before the exec and `cancelled` if the exec fails. `unplanned_starts` in `crates/core/src/health.rs` skips a `start` that follows `planned`. The threshold stays at 3.
