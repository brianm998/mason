# s949: a signaled agent CLI is restarted up to three times

Summary: A develop step whose agent CLI exits 143 or 137 with no result is started again up to three times per step run (was once) before it fails.

Seven develop steps failed with "the CLI exited with status 143 and no result". `settle_all` retried a signaled CLI once, so a second signal (a restart storm or a reaper) ended the step. The retry is now bounded by `MAX_SIGNALED_RETRIES` = 3.

Not verified: nothing driven end to end; only the existing unit test covers the classifier.
