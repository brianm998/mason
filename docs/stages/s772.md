# s772: build the remote-run command shims on unix only (#743)

Summary: The remote-run command shims build only on unix, so CI/windows compiles again.

`agentshim::write` and `resolve` use `PermissionsExt`, which Windows lacks. They are now `#[cfg(unix)]`, with a stub that writes nothing, and `jobs.rs` no longer adds the prompt line on Windows. The agentshim tests are unix-only.
