# s913: the source-free note test no longer dirties its own tree

Summary: The test for a diff with none of the planned source files now writes its note outside the test repository, so its third submit no longer fails on an untracked file.

**Cause.** The test put the note at `dir/source-free.txt`, inside the repository that is also the worktree. After the second submit wrote it, the file was untracked, so the third submit's `git status --porcelain` check refused with "the tree has uncommitted changes". Production keeps the note in `task_dir()`, outside the worktree.

**Fix.** The test uses a second tempdir for the note. No validator or production code changed.
