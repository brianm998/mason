# s1181: watchdog tests arm without a real timer

Summary: The fake-driven WatchdogTests arm the watchdog with a timer-free `arm(config:log:)`, so a stalled runner can no longer fire a real 250 ms tick into their hand-driven state.

## Cause

Three tests called `start()`, which creates a real `DispatchSourceTimer`, then read and wrote `Fake.held` and `Fake.lines` from the test thread. A 250 ms runner stall let the timer append a ping from a background queue: a data race that breaks `held.count`. The two failing test names in run 45883735030 were not confirmed from the full log.

## Change

- `MainThreadWatchdog.arm(config:log:)` sets config, stats, in-flight and log under the lock, with no timer. `start()` uses the same code.
- testABlockedMainQueueIsOneSampleAndOneLine, testAHiddenPingCountsInTheBackgroundWindowOnly and testOnlyAPingOverASecondIsLogged call `arm`. Only testStartWithTheReleaseConfigCreatesTheTimer calls `start()`/`stop()`.
