# s121: the mascot is the app icon on Mac and Compose

Summary: MASON.app gets an .icns made from the mascot app icon, the unbundled Mac monitor and the Compose window show it too, and the iOS icon file sits beside its Info.plist.

- `scripts/bundle-monitor.sh` builds `MASON.icns` with `sips` and `iconutil` and sets `CFBundleIconFile`.
- `App.swift` sets `applicationIconImage` when the bundle has no icon file (unbundled run); `Mascot.appIconData()` is the loader.
- `Main.kt` passes `icon =` to `Window`; `Mascot.appIcon()` is the loader.
- iOS: `AppIcon-1024.png` beside `Info.plist`, with a comment on wiring; no Xcode project made. Android untouched.
- Feature `app-icon` added to `clients/features.toml` as done in both.

Not verified: I did not run the bundle script, the unbundled monitor or the Compose app, and nothing was compiled by me, so the icon in Finder, the Dock and the window is unchecked by eye. Only `plutil -lint` on the iOS plist and the exit script's checks were run.
