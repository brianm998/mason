# s721: shard the daemon CI leg

Summary: The `CI/test` daemon leg is split into three shards per system by test-name checksum, with a script that fails when any daemon test is in no shard or in two.

Task #720. The daemon leg (`cargo test -p mason-daemon`) was cut off at 45 minutes on ubuntu-latest in several runs. Cause (inferred, not measured): most tests start a scratch daemon, and on a 4-vCPU runner `world_limit()` allows 2 at a time. `cargo test -p mason-daemon -- --list` prints 1131 tests across the daemon's test binaries; each shard gets about a third.

- `scripts/daemon-shard.sh K N` prints shard K's test names; `ci.yml` runs them with `--exact`.
- `scripts/check-daemon-shards.sh` proves the shards cover the list exactly once; it runs in the `dshard 1` legs and in `scripts/exit/s721.sh`.
- No timeout, `MASON_TEST_WORLDS`, `rest` leg or test was changed; nothing is ignored.

Trust: `.github/workflows/ci.yml` is PROTECTED (`gates: CI`). This change is not auto-approved; it needs the owner's approval. The shard split is unmeasured until the next CI run.
