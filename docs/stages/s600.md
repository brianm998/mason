# s600: expired overrides are swept

Summary: The sweep deletes overrides past their expiry, and the `expired_switches` finding reports overrides only, so it no longer fires forever on rows nothing removed.

**Cause.** `Store::expire_overrides` was never called in production; the detector kept reporting the inert rows.

**Change.** `sweep_once` step 4d calls it (housekeeping, files nothing). `expired_switches` drops the quarantine half: quarantine rows are ledger history.
