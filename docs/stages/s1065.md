# s1065: the s77 exit test's hand runs say they are a person's

Summary: The s77 exit script starts its two hand runs with `--origin person` and waits to see the first one holding `compile` before starting the second, in place of a one-second sleep.

## Cause

`CI/exit-scripts (ubuntu-latest, 2)` failed twice on develop 0de921ceb (run 45361042086) in s77, s452 and s902.

- s77: since s552 a run with no `--origin` counts as a person's only from a terminal outside a task or agent session (`origin_of`, crates/cli/src/resources.rs). The script's background runs have no terminal, so "by hand 2" could not be seen as interactive. It also relied on `sleep 1` for the first run to hold the slot.
- s452 and s902: see decision 1054.

## Change

Only `scripts/exit/s77.sh` (owner approved both edits): `--origin person` on both hand runs, and a poll of `m resources --json` holders for "by hand" with a 20 s deadline. The interactive assertion and its deadline are unchanged. No daemon or CLI code changed.

## Verified

`bash scripts/exit/s77.sh` on macOS prints `s77 OK`.

## Not verified

The Linux job was not run here. The full CI log was not read (no network). s452 and s902 are not fixed, so the job can stay red on them.
