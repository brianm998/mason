# s182: landing_idle_ms is the current idle spell, not a lifetime total

Summary: The landing queue's idle counter is reset when a batch runs or the queue empties, so `landing_idle_ms` no longer accumulates forever and falsely flags a healthy queue.

**Cause.** `form_and_start` (`crates/daemon/src/landing.rs`) only ever added to `idle_ms`.

**Built.** `State::note_idle` adds while tasks wait with nothing running and clears otherwise. Unit test `idle_tests`. Exit test: `scripts/exit/s182.sh`.

**Not verified.** Tasks held deliberately (freeze, batch delay) still count as idle.
