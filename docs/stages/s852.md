# s852: the hung-git deadline test no longer asserts on wall-clock time

Summary: `a_hung_git_is_killed_at_its_deadline` no longer asserts that it finished within 3 s; it checks `timed_out`, the "timed out" message and that the helper process is gone.

**Cause.** CI run 44920526499 failed at `assert!(t.elapsed() < Duration::from_secs(3))`. The measured window also covers the first `program()` call, which runs an untimed `xcrun -f git` inside a OnceLock on a busy runner. That is a plausible but unproven cause; the assertion is a timing assertion either way, which the repo forbids.

## Built
Removed the `Instant` and the elapsed assertion from the test in `crates/landing/src/git.rs`. No production code changed.

## Tests
The three `deadline_tests` via `run_check`.

## Not verified
That the xcrun lookup was the actual source of the delay on the failing runner.
