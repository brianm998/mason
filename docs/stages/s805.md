# s805: CI-watch auto-approval for reds confirmed on two runs

Summary: `[watch.ci] auto_approve = "confirmed"` files a CI-watch ticket approved when its red was seen on two consecutive runs of the job and no open task covers it (trust-file tickets stay proposed, at most `auto_approve_max` open), with shards and systems of one failure folded into one ticket.

Task #781. Decision 0798.

## Built

- Rule (`crates/core/src/ci_watch.rs`, no I/O): `auto_approve`, `auto_approve_max`, `open_approved`; two-run confirmation, shard/system folding, cap.
- Config (`crates/definition/src/watch.rs`): the two keys, default off.
- Daemon (`crates/daemon/src/ci_watch.rs`): `names_trust_file` turns an auto ticket back into proposed; `auto` is saved and shown in the view; CLI prints "auto-approved".
- Tests: core rule tests (once: proposed; twice: approved; covered: nothing; shards fold; two systems; cap) and a definition parse test. No timing assertions. Exit: `scripts/exit/s805.sh`.
