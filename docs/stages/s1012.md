# s1012: a takeover keeps in-flight checks

Summary: a replayed run_check carries its call id, takes the suites that finished before a masond takeover instead of running them again, and no longer folds the base on the replay.

## Cause

A takeover cut a develop agent's `run_check` off; `mason-mcp` sent it again, but the new daemon handled it as a new call: it folded the base (a new tree key, so every suite ran again) and a suite that finished in the old daemon was already marked delivered, so it ran again too.

## Change

- `mason-mcp` adds a `call_id` to each `run_check` and sends the same one on a replay (`CheckScope.call`).
- `hostedcheck::hold_results` / `answered`: while a call with an id runs, a finished run of its task stays undelivered. It is delivered when the reply has been written to the contract socket (`CheckHandler::answered`, called by `serve_conn`). A replay with the same tree and command takes the result.
- `TestChecks::run_scoped` writes `t<task>r<run>.call` (call id and fold note). A call whose id is in it is a replay: no `basefold::fold`; the answer repeats the first fold note and says if the base moved since.
- A replay says in the task's progress what it took over ("picked up after a restart: cargo-workspace kept (passed), exit-scripts running").
- Test steps: nothing changed. `suites::run_suite` already records evidence per tree and suite as each suite passes (`put_evidence`), and `recover` re-runs the step, which reuses it ("green for this exact tree already"). Narrowed suites record none by design and run again.

## Not verified

- No end-to-end run with a real masond and a fake GitHub; the tests drive `hostedcheck` with local step hosts (`crates/daemon/tests/it/hosted_check.rs`). The fold skip and call file in `run_scoped` have no test of their own, and the test-step claim above was read from the code, not run.
- A suite run on GitHub is re-collected from its `.remote` record; that it is found again after being finished and collected once was not tried.
- #823 (cancel an uncollected run) is not merged here; it must not cancel a held, undelivered run a replay will take.
- The exit script runs the unit-level tests, not a real masond takeover.
