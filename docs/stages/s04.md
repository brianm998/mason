# Stage 4: Step host

## Built
`crates/step-host` (`mason-step-host`): a library plus two binaries.
- **`step-host`** (the detached supervisor, `src/host.rs`): calls `setsid` so it has its own session, owns one child (in its own process group, stdout and stderr merged into one pipe), journals every byte to `journal`, and serves controllers on a unix socket. The child never blocks on a controller. It writes `exit.kv` once the child has gone and its output is drained, lingers for a controller to collect the result (a `Release` frame, or a configurable linger timeout), then leaves. Files stay on disk.
- **Protocol** (`src/protocol.rs`): length-prefixed frames, **version 2 (current) and 1 (previous) both accepted**; v2 adds heartbeat frames. Negotiation picks the highest common version and refuses others with a reason. `Hello`, `Attach{offset}`, `Stop{grace}`, `Release`, `HelloAck`, `Data{offset, bytes}`, `Exit`, `Heartbeat`.
- **Registry** (`src/registry.rs`): a directory per host (`host.kv`, `journal`, `exit.kv`, `hb`, `sock`). `Registry::scan` classifies each host as **Running**, **Exited** (record on disk) or **Lost** (host gone with no record), with last heartbeat and journal length.
- **Reattach** (`src/client.rs`): `HostClient` (connect, attach from a byte offset, stop, release) and `collect_to_file`, which resumes from the size of what it already has, uses the socket when the host is up and the files on disk when it isn't, and verifies contiguity and the final length.
- **Heartbeats for leases:** the host rewrites `hb` atomically every interval (so a restarted daemon can see it's alive with nobody attached) and sends `Heartbeat` frames to attached v2 controllers.
- **Launcher** (`src/launcher.rs`) and **`step-host-ctl`**, a stand-in for the daemon used by tests and the exit script.
- Resume is by **byte offset**, so a controller killed mid-write of its own file resumes exactly, with no frame bookkeeping.

## Exit test
`bash scripts/exit/s04.sh` passes locally: unit and integration tests, then three rounds of: start a 200-line, 10 ms/line command under a host, `kill -9` the controlling process after a different amount of output each round, confirm the host is still alive and still journaling, start a brand new controller, and require an identical 200 lines and exit status 9.
```
round 1: controller killed after 62 lines; host 88929 alive; journal 647 bytes
round 1: no loss, no duplicates (200 lines)
round 1: exit status 9 seen
... (rounds 2 and 3 the same) ...
s04 OK
```

Integration tests (17, repeated 6 times without a failure): output and exit status with stderr merged; host is a session leader and shares its session with the child; resume by offset after the controller drops; protocol v1 and v2 accepted, future-range negotiated down, alien range rejected with a reason; heartbeats to v2 and the file advancing unattended; registry Running/Exited/Lost and salvage of a Lost host's output; **controller killed at 4 points during output and 6 points around child exit** (replacement collects everything); **partial/garbage frames and a controller dying mid-write don't hurt the host**; attach beyond the journal refused; stop kills the whole process group and escalates to SIGKILL after the grace period; release ends the host but files stay readable; linger timeout; spawn failure is a result (exit 127 plus message); cwd and env reach the child; 3 MB output streams in order.

## Not run
- **Crash injection at the exact instants the plan names, deterministically.** "During output", "during child exit" and "during a socket write" are covered by killing a real controller process at varied times and by sending torn frames, not by a deterministic hook at each instruction. The crash-injection harness of Stage 6 is where exact effect boundaries get covered.
- Linux run of the new tests until CI reports (the macOS-specific inherited non-blocking socket bug was found and fixed here; Linux is not expected to differ).
- A **host killed while its child runs** leaves the child running (reported as Lost); the daemon-side policy for adopting or killing such orphans is Stage 6/8 work.
- Output of grandchildren that keep the pipe open more than 2 s after the child exits is not journaled.
- Socket path length: limited to 100 bytes (macOS `sun_path` is 104); the host refuses longer paths with a clear error. The daemon's registry root must stay short.
