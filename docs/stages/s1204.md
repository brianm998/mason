# s1204: node mDNS through the system responder

Summary: On macOS the node and LAN listener register `_mason._tcp` with the system responder (null host) so masond no longer answers for the Mac's own `.local` name and macOS stops renaming it; other platforms use their own host name.

See decision 1194. Changes: `crates/daemon/src/dnssd.rs` (new FFI), `lan.rs` (`advertise`, `service_info`, `hostname`), `node_doctor.rs` (advertised name).

Not verified: the reboot rename alert; live `dns-sd -B/-L` (see `scripts/exit/s1204.sh`, which runs the unit tests only).
