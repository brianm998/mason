# s606: CI/windows test build skips the unix-only open_session tests

Summary: The CI/windows test build no longer compiles the unix-only open_session tests, which failed on `std::os::unix` and `Permissions::from_mode`.

**Cause.** `mod open_session_tests` (crates/cli/src/main.rs:4041-4058) imports `std::os::unix::fs::PermissionsExt` and writes a `#!/bin/sh` fixture, but was gated only by `cfg(test)`. It is now `cfg(all(test, unix))`.
