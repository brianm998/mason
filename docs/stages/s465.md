# s465: one wait is one finding

Summary: A slot wait caused by the CPU gate now yields only `overloaded:slots` (with the CPU gate named in its evidence) instead of also firing `overloaded:cpu-gate`, and `overloaded:load` is no longer raised from the sampler's assumed-busy fallback.

See docs/decisions/0458-one-wait-one-finding.md. Keys are unchanged.
