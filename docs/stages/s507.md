# s507: matrix test lists each event once

Summary: `every_state_and_event_pair` passes again because `events()` in the engine matrix test no longer lists `Deferred` and `Undeferred` twice, and a duplicate name now fails with a clear message.

## Why

`events()` had 28 entries but 26 distinct names, so the loop ran 12 x 28 iterations against `assert_eq!(checked, 12 * 26)`. The second `Deferred`/`Undeferred` pair is removed, the test asserts the names are unique, and the count assertion is unchanged. The reducer and the `expected` table are not touched.
