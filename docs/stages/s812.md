# s812: a local fallback from GitHub is bounded like any local run

Summary: a check, test step or debt that was meant for GitHub and that `[remote_runs] fallback = "local"` sends here (no runner picked it up within `pickup_timeout`, or GitHub was down) now takes the machine slots it would hold when placed here before it starts, through the broker, so the slot limits and the CPU and thermal holds apply to it. Before, it had skipped the local queue on its way to GitHub (#759, #761) and started here at once.

Made outside the pipeline on 2026-11-21 at the owner's request (the queue was stuck on GitHub runner waits). Decision 0805.

## Built
- `remote::fallback_lease` (`crates/daemon/src/remote.rs`): asks the broker for `uses`, ranked as the task's own work (or behind everything with no task), beside the step's own request; nothing to take gives `Ok(None)`.
- `hostedcheck::collect`: a run bound for GitHub that falls back takes `spec.holds` (the slots the same check holds when placed here) before its step host starts, unless a local host for it already exists (a restarted daemon collecting it).
- `suites::run_hosted_resuming`: a test step or debt that falls back takes what the definition's test step `uses` (`compile` and `test-suite` for MASON).
- Tests: `fallback_lease::a_fallback_run_waits_for_the_slot_it_would_hold_here_and_gets_it_when_freed`, `fallback_lease::nothing_to_hold_takes_nothing` (crates/daemon/tests/it/fallback_lease.rs). Exit test `scripts/exit/s812.sh`.

## Not changed
- The wait before falling back is the existing `[remote_runs] pickup_timeout` (default 1200 s); set it lower in the registration file to fall back sooner.
- Time a develop agent's check spends in the fallback queue counts as GitHub time (#799's `remote_credited` wraps the whole remote-bound run), so it does not eat the step budget.

## Not verified
- No end-to-end run with a fake GitHub that never assigns a runner; the lease is tested directly.
- The full workspace suite was not run here; `cargo test -p mason-daemon --test it fallback_lease`, clippy and fmt were.
