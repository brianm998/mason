# s492: MascotTest loads Skia in the test JVM

Summary: The Compose test JVM unpacks Skia's native library into the build directory so MascotTest's image tests load it.

MascotTest failed with `java.lang.UnsatisfiedLinkError` on the first `loadImageBitmap`, because Skia's
native library could not be loaded from its default unpack location. The test task now sets
`skiko.data.path` and `java.io.tmpdir` to `clients/compose/app/build/skiko`. No assertion changed and
`Mascot.bitmap()` still catches only `Exception`. Exit test: `scripts/exit/s492.sh`.
