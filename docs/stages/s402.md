# s402: every wait records what it is waiting for

Summary: a wait's class comes from one function of its cause (`cause_class`) and is never empty; a resource with no name is `other`.

Every `WaitStarted` site already passed a class; the empty ones came from a resource with no name, and from the fallback in `targets::wait_class` when the broker had no wait for the task. Both now give `other`. Old events are not backfilled.

Not verified: I did not find which paths produced the 274 classless waits in the live log; this is read from the code, not from the data. The classes keep their existing names (`disk-floor`, `disk-stall`, `llm:<account>`), not the task's list.
