# s753: parse_duration edge-case tests (#748)

Summary: Edge-case tests for `mason_landing::config::parse_duration` (whitespace, upper-case units, bare number, empty, signed, overflow), and a fix so an overflowing value returns `None` instead of panicking (debug) or wrapping (release).

**What changed.**
- `crates/landing/src/config.rs`: `parse_duration` uses `checked_mul`/`checked_add`. Before, `"18446744073709551615h"` overflowed `n * unit`. Other cases already behaved sensibly (trimmed outer whitespace only; lower-case units only; `"1h30m"` works; bare numbers, empty and negative inputs give `None`).
- New tests `duration_edge_cases` and `duration_overflow_is_none_not_a_panic`.

**Trust.** `crates/landing/**` is protected; the change is tests plus the overflow fix.

**Not verified.** Only `run_check` results (listed in the submission) back the tests; the exit script only greps for the tests.
