# s719: the daemon's takeover_drain and update tests are unix-only

Summary: The daemon's takeover_drain and update integration tests are unix-only, as the support module they import from already is, so the Windows CI test build compiles again.

**Cause.** Both files import `support::orphans::blocking_loop`, and `orphans` is `#[cfg(unix)]` in `crates/daemon/tests/support/mod.rs`, so on Windows the import was unresolved (E0432).

**Change.** `#![cfg(unix)]` at the top of both files, as `it/orphans.rs` already has. No other code changes; unix coverage is unchanged.
