# s86: contain panics on daemon threads

Summary: A panic on a background loop, a landing batch, `admit` or the store writer is now contained (loops go on and file a `thread_panic` bug, a batch fails its tasks and frees its slot, the writer ends the process so launchd restarts it), and `mason status` and `mason doctor` show it.

MASON caught panics only on job and pool threads. Now:

- `bg::spawn_loop` (crates/daemon/src/bg.rs) runs each pass of a named loop under `catch_unwind`; a panic is logged, filed with `record_bug("thread_panic", ...)`, and the loop resumes after 500 ms. Used by the landing coordinator (now one pass per call, so `coordinators` can never name a dead thread), `sweeper`, `definition-watcher`, `tracker`, `introspect`, `progress-ticker`, `update-check`, `usage-probe` and `targets`.
- A landing batch thread catches a panic, delivers `Verdict::Failed("internal error: the landing batch panicked")` to each task of the batch that has no verdict yet (new `owed` set in the landing state), and a drop guard clears its slot in `running` on every way out.
- The store writer thread exits the process with status 70 on a panic.
- `admit()` resets `admitting` in a drop guard.
- The reader lock recovers from poisoning.
- `/status` has `thread_panics {count, last}`; `mason status` prints `THREAD PANICS`, `mason doctor` warns.
- Injection: `MASON_PANIC_AT=<point>[@n]` (crash.rs): `coordinator`, `batch`, `admit`, `loop:<name>`.

Tests: crates/store/tests/store.rs (poisoned reader; writer panic exits 70), crates/daemon/tests/panics.rs (coordinator, batch, admit, loop against a real `masond`). Exit test: scripts/exit/s86.sh.

Not verified: a panic in the middle of a real landing (after a push or pull request was made) leaves the integration branch or candidate ref behind until the coordinator's next start-up sweep; that case is not tested. Threads not listed (cpu-sampler, task cache, step-host helpers, the update loader) are not covered. `crates/daemon/src/landing.rs` is a guard file: this change touches it and needs the owner's approval.
