# s241: updates from published releases for packaged installs

Summary: A packaged install now updates from the newest GitHub release (`release` channel): the tarball for its platform is downloaded, checked against SHA256SUMS, unpacked into runtimes/<version>/, self-tested and taken over, and the monitors' banner opens the download page.

See docs/decisions/0236-release-update-channel.md. Code: `crates/daemon/src/release.rs`,
`update.rs` (`Channel::Release`, `prepare_release`, `check_release_move`, `assess_release`),
`schemas/mason.proto` (UpdateInfo 4, 5), both monitors' daemon button. Tests:
`crates/daemon/tests/update_release.rs` (good update with and without `--check`, checksum
mismatch, no asset for the platform, downgrade refused) and unit tests in `release.rs`.

Not verified: the real GitHub API, Windows, and compiling the Swift/Kotlin edits. No protected
file was changed (selftest.rs is only called; deny.toml untouched since curl is used).
