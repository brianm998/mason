# s1255: monitors show and change the GitHub runner limit (#1261)

The Mac, phone and Compose monitors show the `gha` and `gha-macos` pools beside the compile limit,
with minus and plus that send `SetLimit`.

- Protocol (additive): `RunnerPool` and `HomeView.runner_pools = 17` (limit, ceiling, used, MASON's
  share, other workflows', waiting). Always sent, so an idle view can raise the limit.
- Daemon: `views::runner_pools` reads the broker's existing snapshot; `POST /resources/limit` is now
  owner only (see decision 1245). `mason resources limit` says who it is, as `gate` does.
- Monitors: `RunnerLimit` (Swift `MonitorCore/RunnerLimit.swift`, Kotlin `RunnerLimit.kt`) holds the
  bounds (0 to the ceiling) and the words; `RunnerLimitRows` draws them. `gha_ceiling`, `gha-debt`
  and `gha_full_share` stay CLI only.
- Tests: Swift and Kotlin model tests, an offscreen Swift snapshot, daemon test
  `runner_limit.rs`, exit script `scripts/exit/s1255.sh` (with `conformance runner-limit`).
