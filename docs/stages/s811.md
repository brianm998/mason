# Stage 811: the row-redraw tests pump the run loop

Summary: The row-redraw tests drain the main run loop around each ImageRenderer read, so observation-driven progress views run again and the two RowRedrawTests reds pass.

## Cause
s771 (0764) moved the tests from a window to ImageRenderer and dropped the run-loop turns from `settle()`. Reading `cgImage` alone does not run SwiftUI's observation-driven updates, so the LiveProgress bodies never re-ran and the progress-view counts stayed 0 (RowRedrawTests.swift `draw`).

## Change
`draw()` drains the main run loop before and after reading the image. ImageRenderer, every bound and every test name are unchanged. s811.sh runs the class and checks the s237 line.
