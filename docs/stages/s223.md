# s223: release packaging scripts (tarball, .deb, SHA256SUMS)

Summary: `scripts/package/` builds the per-target `mason-<ver>-<target>.tar.gz`, the Linux `mason_<ver>_<arch>.deb` and a `SHA256SUMS` for a release folder, and an exit script installs the host tarball with `scripts/install.sh`.

Task #226. Decision 0218.

## Built

- `scripts/package/lib.sh`: version from `Cargo.toml`, `pkg_build` (cargo build of the four bins for a target, strip, ad-hoc `codesign` of every Mach-O on macOS unless `MASON_CODESIGN_IDENTITY` is set; `MASON_PACKAGE_NO_BUILD=1` reuses a build).
- `tarball.sh <target> [--out DIR]`, `deb.sh <target> [--out DIR]`, `checksums.sh DIR`.
- `docs/RELEASING.md`: the tarball and .deb layout.
- `scripts/exit/s223.sh`: tarball, checksums, `install.sh` from a `file://` release, `mason --version`; the .deb through `dpkg-deb` on Linux only.

## Not done, not run, not verified

- `deb.sh` was never run: this Mac has no `dpkg-deb`. The Linux release job must install it for real.
- Cross-target builds (other arch, Linux from macOS) were not tried; `strip` of a foreign binary only warns (set `STRIP`).
- No real signing identity or notarization.
- `postinst` mentions `mason service install`, which belongs to the service task and may not exist yet.
- `scripts/exit/s223.sh` is a gate and waits for the owner's approval.
