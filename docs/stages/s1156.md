# Stage 1156: the cause line of a red exit script (#1200)

Summary: A red exit-script run now names the failing line as the cause, not a `== ` heading or prose that contains the word "error".

## What changed

- `scripts/run-exit-scripts.sh` `cause_of` skips `== ` headings and matches only the forms a
  failure is reported in (panic, `FAIL`, `not ok`, `timed out waiting`, compiler and tool
  `error:` lines). With none it names the last line, as before.
- `scripts/exit/s1156.sh` runs the runner over scratch scripts and checks each cause.
- The two reds of #1200 are explained in decision 1145. Neither s22 nor s777 is changed here.

## Held for the owner

`scripts/run-exit-scripts.sh` is a protected gate, so this change waits for approval.
