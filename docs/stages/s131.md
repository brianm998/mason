# Stage 131: dropped-line audit

Summary: Landing now checks that a conflict resolution kept every line the base had landed, sends the task back naming each dropped file and line, and lets a submission list deliberate removals.

**What was built.** `crates/landing/src/audit.rs`: a pure rule function (`unkept`) plus the git-backed `audit`; call sites in `submit_and_wait` (merges of the base in the task's branch) and `Batch::assemble` (after a resolver commit; the merge is undone and the rest of the batch lands); `removes` in `submit_change`, saved to `change.json` and shown in task detail. Decisions: `docs/decisions/0117-dropped-line-audit.md`.

**Protected files changed (owner approval).** `crates/landing/**` (the gate itself: audit module, `batch.rs`, tests), `crates/daemon/src/landing.rs` (the two call sites, the send-back), `crates/adapter-api/src/contract.rs` (the new optional `removes` field). `protect.rs` and `selfguard.rs` are untouched.

**Exit test.** `scripts/exit/s131.sh` runs the unit, git-backed, batch, contract and end-to-end tests. The end-to-end daemon is in-process (the `Scratch` harness: real git, bare origin, real step hosts, fake-claude), not the `masond` binary. The base's landing is done by the fake agent's script, not by a second task.

**Existing tests changed.** Two e2e tests (`crates/daemon/tests/e2e.rs`, the conflict-with-the-base ones) resolved a conflict by writing `both` over `conflict.txt`, which dropped the base's `theirs` line; the audit rightly flags that. Their resolutions now keep `theirs` and the assertion expects `theirs\nboth`. No gate or limit was loosened.

**Not verified.** `cargo fmt`, `cargo clippy`, `run-exit-scripts.sh`, `check-spdx.sh` and `check-pure.sh` were not run by me. The `tests` check passed (the workspace tests, including the new ones). Direct `cargo` is refused in this environment, so the exit script's output is not recorded here and was not run by me; the code was checked only through the `tests` check. Not tried against a real agent. Limits are listed in the decision record.
