# Stage 129: Active models matches the sessions in progress

Summary: The home page's "Active models" list now shows only tasks whose agent step holds a granted LLM lease, so it agrees with the "Sessions: n of m" stepper and is empty when no session runs.

**What changed.** `Broker::llm_held_by(task)` (granted leases only, not waiting ones) in `sched.rs`; `Views::home` uses it instead of "task is in a step state with a model". Tasks waiting for a slot, held, awaiting an answer or between steps are no longer listed. `sessions_used` is unchanged. A lease on an `llm:` resource is never hidden: if the row has no model, the entry falls back to the display name, then the step name. Lowering a limit below what is held changes nothing about which running sessions are listed. Clients render `model.home.active` as is (`Pages.swift`, `Pages.kt`), so neither changed.

**Not verified.** Nothing run directly (build queue); tests ran through `run_check`.
