# s439: the top-bar mascot yields width

Summary: the Swift top bar's mascot picture no longer counts toward the bar's minimum width, so TopBarFitTests passes again at the 1000 pt window minimum.

## Why
The mascot (s334) was a fixed 81.6 pt frame plus an 8 pt gap, lifting the minimum to 1079.6 pt.

## Change
`topBarMascot` frame is min 0, ideal and max `side`, with layout priority -2 so it gives way first. `topBarMascotSide` is unchanged.

## Measured
Before: 1079.6 pt (reported by the test). After: see the test run; expected about 998 pt.

## Not verified
The mascot's look at normal widths was not rendered. Compose TopBar.kt is unchanged; parity is a follow-up.
