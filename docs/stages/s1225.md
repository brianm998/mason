# s1225: a suite a node gives back stays off the coordinator (#1238)

`run_hosted_resuming` (suites.rs) used to treat `run_on_node` returning `None` as "run here". Now,
when `hostedcheck::stays_off_for` (the rule `stays_off_this_mac` shares: `[remote_runs]`, mode
`remote`, fallback not `local`) holds, `off_machine_until_placed` re-places the suite: GitHub, then a
node with room, then backoff waiting (skip and shutdown honoured). No local slot, no step host.
No possible place, or a node without the base / unknown base ref, gives `env_err` (an outage the
test step already waits on, charged to no task). Where the run may run here, the old path is
unchanged. Callers with a place: test step, landing batch suite, rerun. Baseline, ledger and
build runs pass no place and stay local.

Not verified: no new automated test (no public entry point drives a suite through
`run_hosted_resuming`); only `cargo check` was run before `run_check`. The exit test with
`mason node stop-jobs` was not run by hand.
