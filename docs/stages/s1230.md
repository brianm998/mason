# s1230: the lost-host test waits for the host's record

**Cause.** `a_node_job_whose_host_dies_leaves_no_grandchild_behind` waited only for the
grandchild's pidfile, then scanned the host registry and asserted one host. The host writes
`host.kv` after spawning its command (`crates/step-host/src/host.rs`), so under load the
grandchild could run while the scan still found no host.

**Change.** The test waits, with `support::wait_for`, until the host is on record before it
scans. The one-host assertion is kept. No sleep, no timing assertion, no code change outside the test.

**Exit test.** `scripts/exit/s1230.sh`.
