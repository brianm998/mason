Summary: The session answer now carries the provider, binary and exact resume argv (Claude `--resume <sid>`, Codex `resume <thread>`), and `mason task open` runs that argv in the worktree and explains a failed resume instead of leaving a bare provider error.

**Change.** `attention::session_for` returns `provider`, `bin` and `argv` (a fresh-session argv when there is no id); `resume_argv` builds it. `mason task open` (`run_session` in `crates/cli/src/main.rs`) runs it with the worktree as cwd; an older daemon without `argv` still gets Claude's command. A non-zero exit of a resume prints why (wrong working directory or config dir). Flags and the confirm question are unchanged.
