# s249: the test step runs the exit scripts a change touches, and an open task stops a nightly failure being filed twice

Summary: an `exit-scripts` suite runs the exit scripts a change adds or edits relative to its merge base and reads one `PASS sNNN` / `FAIL sNNN` line per script, and the `base-health` schedule no longer files a failure whose task is still open.

Decision 0244 records the choices and what the exit scripts did at origin/develop.

**What changed.**
- `scripts/run-changed-exit-scripts.sh` (new, protected): the helper. It lists `scripts/exit/*.sh` that the change adds or modifies against `git merge-base $MASON_BASE HEAD` (default `origin/develop`), skips `-real` and `-manual` scripts, runs each, prints `PASS`/`FAIL` plus the tail of a failing script, and exits non-zero if any failed.
- `.mason/mason.toml` (protected): `[suite.exit-scripts]` (regex parser, `min_tests = 1`, `level = "unit"`, so it is bound like the others), the suite in the test step's list, and `"scripts/exit/**" = ["cargo-workspace", "exit-scripts"]` in `[impact]`.
- `crates/daemon/src/schedule.rs`: `base-health` skips a failure with an open task of the same title (`same_open_title`, unit tested).
- `scripts/exit/s249.sh` (protected): a temporary repository with a passing, a failing, a real and an untouched red script.

**The nightly run of every exit script (owner's overlay; not edited).** Add to the project's overlay:

```toml
[schedule.exit-scripts]
kind = "base-health"
every = "daily"
command = "bash scripts/run-exit-scripts.sh 2>&1 | grep '^FAILED: scripts/exit/' > exit-failures.txt; true"
parser = "lines"
results_file = "exit-failures.txt"
timeout_s = 14400
```

The first run records what is red as the baseline and files nothing; later runs file one low-priority task per newly red script, titled "exit-scripts is red on origin/develop: FAILED: scripts/exit/sNNN.sh", and not again while that task is open.

**Not verified.** The suite was not run by the test step itself, only its helper (s249) and the definition lines (checked for presence, and the daemon's own tests parse the file). The baseline of all exit scripts at origin/develop was not completed; see decision 0244. The nightly lines were not run.
