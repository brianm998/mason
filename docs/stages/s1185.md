# s1185: full CI does not rerun cancelled or outdated runs

Summary: A full CI run that was cancelled by hand, or whose commit develop has moved past, is no longer rerun (nothing is filed and a fresh run follows), and a manual `schedule run` cancels a rerun of an outdated commit.

- `ci_schedule::follow`: run conclusion `cancelled` ends the follow as cut off; failures on a commit that is not develop's head are superseded (no rerun, no tickets).
- `take_over_outdated`: a manual run cancels a followed rerun of an outdated commit and dispatches on the head; a rerun of the head is left alone.
- `Host` gained `cancel_run`.

Not verified: the real GitHub cancel call against a live run; tests use the fake host. Superseding looks at whether develop's head differs from the run's commit, not which paths changed. A job cut off at its time limit leaves the run `failure`, so it is still handled by `ci_infra::judge` as before. `ci_watch.rs` was not touched: it files for develop reds, not from this follow.
