# s464: the CPU-gate finding counts time held

Summary: The CPU-gate finding now counts only time a task has actually spent under a CPU cause (Cpu or Settling), accumulated per task, instead of the age of its whole wait.

The finding used the age of any wait whose text contained "cpu", so a 21 s settle on a task
queued for 90 min fired it. The broker now matches on the wait's cause and accumulates time per
task (`CpuHold`, capped per pass so a paused daemon adds little). The threshold is unchanged.
