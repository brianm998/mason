# Stage 715: row-redraw tests draw on a headless runner

Summary: The row-redraw tests now run a full layout, display and bitmap draw cycle on their never-ordered-in host, so CI/monitor-swift sees rows drawn on the headless runner.

CI/monitor-swift was red on develop with `s237: 0 RowView body evaluations`, so the three
"rows were drawn" preconditions in `RowRedrawTests` failed. `host()` and `settle()` now share a
`draw()` that flushes `CATransaction`, lays out, displays and caches the display, turning the run
loop between passes. The `> 0` preconditions stay, and the recorded-stream test now also asserts
`used > 0`. `scripts/exit/s715.sh` requires a non-zero RowView count.
