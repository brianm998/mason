# s1077: the macOS exit-script watcher no longer holds the pipe

Summary: The macOS exit-scripts job gets 90 minutes, and an exit test proves that a finished script no longer waits for the no-timeout watcher's sleep.

## Cause
`run_limited` (scripts/run-exit-scripts.sh:74) started `( sleep "$limit"; ... ) &` inheriting the pipe to `tee`. Line 77 killed only the subshell, so its `sleep` kept the pipe open and `tee` never saw EOF. Run 45361042086 shows `s02 OK`, no timing line, then cancellation an hour later with an orphan `sleep`.

## Change
While this task ran, develop landed the runner fix itself (c1e58b9b7 kills the watcher's `sleep`, 24a4fd4e6 detaches its stdio), so this change leaves run-exit-scripts.sh as develop has it. It raises ci.yml exit-scripts-macos from 60 to 90 minutes (decision 0842).

## Tests
scripts/exit/s1077.sh runs the runner without timeout/gtimeout and a large limit, then checks it finished and left no `sleep 7717`.
