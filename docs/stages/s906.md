# s906: the fake host checks out without tar

Summary: The fake host materialises a PR head with git read-tree and checkout-index instead of git archive piped to tar, so its checks run on Windows.

## Cause
`crates/adapters/src/fakehost.rs:130-148` on origin/develop ran `git archive | tar -x` through Git Bash. The CI/windows log shows tar "Cannot open ... No such file or directory", so the run returned Red uncached and the merge tests saw "checks have not passed".

## Change
`checks_of` runs `git read-tree <sha>` and `git checkout-index -a -f` with `GIT_INDEX_FILE` outside the work tree. A failure still returns Red and writes no cache.

## Not verified
The Windows CI run has not been verified in this session. If it is still red, the next suspect is `test -f b` under Git Bash.
