# Stage 162: Warn when suites are bound to the test step but it lists none

Summary: `validate::warnings` now warns when suites are bound to `test_step` and no test step lists any suite, so `mason doctor`, definition apply and the monitors show the state.

## Built
- `unlisted_suites` in `crates/definition/src/validate.rs`, called from `warnings()`. One warning, path `step.<name>.suites`, naming the test step(s), the bound levels and the fix (`suites = [...]`, or remove the binding).
- Tests in `crates/definition/tests/testing_tables.rs`; exit test `scripts/exit/s162.sh` (real `masond`, `mason doctor`).
- It adds a warning and refuses nothing. What a test step without suites runs is unchanged. `validate.rs` is a protected file (definition validation), so it waits for the owner's approval.
