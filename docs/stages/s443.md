# s443: MonitorUI's AppKit uses sit behind platform checks

Summary: MonitorUI's AppKit calls (click count, pasteboard, occlusion, cursors) are behind `#if canImport(AppKit)` with iOS equivalents, and `MonitorUI` is now a library product.

## What changed

- `Components.swift`: tile taps go through `tileTapped(model:state:clicks:)` on both platforms; macOS reads the click count from the current event as before, iOS uses `TapGesture(count: 2)` (priority) plus a single tap. Copy uses `UIPasteboard` on iOS. `SharedTick` takes visibility from `setVisible(_:)` on iOS.
- `Root.swift`: iOS reports `scenePhase` (active = visible) to `SharedTick`; the sidebar handle cursor is macOS only. `Pages.swift`: the pointing-hand cursor is macOS only.
- `Package.swift`: `.library(name: "MonitorUI")`.
- New `TileTapTests` (single → 1, double → 2 reach `tileClicked` as on the Mac). Exit script `scripts/exit/s443.sh`.
