# s859: the fake host runs its checks through the project shell (#828)

Summary: The fake git host now runs its archive and checks commands through `shell_command` and `to_shell_path` so they work on Windows, and a check run that could not happen is no longer cached as red.

**Cause.** `FakeHost::checks_of` used a bare `sh` and Windows paths; on the CI/windows runner the tar step failed and the failure was cached as red for that SHA.

**Change.** `crates/adapters/src/fakehost.rs`: both commands go through `mason_platform::shell`; a failed archive or shell start returns red without writing `checks/<sha>.json`.
