# s649: a short narrowed test step takes the test-small lane

Summary: The test step's narrowed cargo suite now takes `test-small` instead of `test-suite` when every selected test target has a recorded median run time and they sum to under the project's `small_run_s` (default 180 s); times come from libtest's per-executable summary lines and are kept in a new `target_times` table.

**What changed**
- `crates/store`: migration `target_times`, `record_target_times`, `target_medians` (median of the last 10 runs per project, suite and target).
- `crates/daemon/src/targettimes.rs`: parses a log (`Running ... (deps/name-hash)` or `Doc-tests x`, followed by `test result: ... finished in X.XXs`) into one entry per executable, maps `-p pkg --lib/--bins/--doc/--test t` groups to those keys, and sums medians.
- `crates/daemon/src/suites.rs` (protected, owner approval needed): every judged run records its target times, whole or narrowed; a narrowed step with target groups asks `small_run`, and if small swaps the lease through `jobs::small_lane` (the one rule, shared with `run_check`). The wait text starts "small run, est. 70 s: ...".
- `crates/daemon/src/jobs.rs`: `acquire_needs_labeled` carries the wait-text prefix; `small_lane` doc updated.
- `crates/daemon/src/config.rs`: project setting `small_run_s` (0 turns the rule off).
- No limit changed; `.mason/mason.toml` unchanged.

**Not verified / limits**
- Not run by hand: the shell sends cargo through the build queue; only `run_check` ran tests. The exit script `s649.sh` runs the unit tests, not a broker lease listing with a scratch store.
- Keys are executable names without cargo's hash, so two packages with a test target of one name (e.g. `it`) share a median, and a crate's lib and bin unit tests share the package key (summed). A shared name can under-estimate a heavy target.
- `{packages}` narrowing (whole packages) and `--workspace` groups stay on `test-suite`: their targets are not enumerated.
- The format of the `Running` line was taken from cargo's usual output, not checked against a live log of this workspace.
- The "test-small count" is untouched.
