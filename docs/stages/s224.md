# s224: universal MASON.app in a .dmg, signed and notarized when asked

Summary: `scripts/package/macos-dmg.sh` builds `MASON-<ver>-macos.dmg` (universal Swift monitor plus an /Applications link), and with `SIGN_APP` signs the app and dmg (hardened runtime, timestamp) and notarizes via the new `scripts/package/notarize.sh`; `bundle-monitor.sh` gains `--universal` and signing, its default path unchanged.

Task #228. Decision 0219.

## Built

- `scripts/bundle-monitor.sh`: `--universal`; `SIGN_APP`/`SIGN_IDENTITY`/`ENTITLEMENTS`; accepts the `Contents/Resources` layout universal builds give the resource bundle.
- `scripts/package/macos-dmg.sh`, `scripts/package/notarize.sh` (new here; the .pkg task reuses it), `scripts/exit/s224.sh`.

## Not verified

- Whether the signed app runs (never launched, by rule). No entitlements file: the monitor needs none under the hardened runtime as far as the code shows (no JIT, no unsigned memory, no mic/camera); not tested on a signed build.
