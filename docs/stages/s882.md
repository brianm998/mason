# s882: idle-debt tests reused the task's own evidence

Summary: The three idle-debt tests failed because `owe` left the task's evidence and gave its debts no landed commit, so the idle pass skipped them; origin/develop already carries the same fix in `owe`, and this note records the cause.

**Cause: a fault in the test helper.** `owe` (crates/daemon/tests/it/testing.rs, `fn owe`) put the debts back and cleared `suite_green` and `suite_skip_green`, but not `evidence`. The task's own run had recorded evidence for the landed tree, so `run_suite` (crates/daemon/src/suites.rs, "Identical code never tests twice") returned `Reused` and the counted script never ran: the log stayed empty (runs 0, want 1) while the pass reported a green suite. No change to suites.rs (PROTECTED) was needed.

**Second part of the cause.** A debt added after landing had no `landed` commit and its task branch was gone, so `debt_landed` (suites.rs, `fn debt_landed`) gave `None`: `next_pick` and `settle_debts` skipped it (runs 0, debt still open). `owe` now calls `set_debt_landed` with the base tip.

**State at merge.** origin/develop changed `owe` the same way while this task ran (set_debt_landed and clearing evidence), so the merge took develop's version and this task's change to `crates` is empty.
