# s585: the mascot cache test starts from an empty cache

Summary: `testImagesAreBuiltOnceAndThenServedFromTheCache` empties the shared mascot cache first, so it no longer fails when an earlier test has already built `icon:queued@24`.

**Cause.** `Mascot`'s cache is process-wide; `testEveryIdInTheManifestLoads` runs earlier and builds the images the cache test expects to build, so `imageLoads == after`.

**Change.** An internal `Mascot.emptyCacheForTests()`; the test calls it first. The `after + 1` assertion is unchanged; production behaviour is unchanged.

**Tests.** `swift test --filter MasonMascotTests`, and the full package.
