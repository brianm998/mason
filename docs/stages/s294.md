# s294: custom agent steps get their own instructions; fix and conflict packs

Summary: An agent step can name its own prompt file (`prompt = "<file>"` under `.mason/prompts/`, read from the base commit), and a develop round sent back by a red test or a conflict uses a `fix` or `conflict` pack before `develop.md`.

## Built

- `prompt` key on agent steps (`model.rs`, `parse.rs`): relative, no `..`, no backslash, not empty; other step types reject it.
- `prompts::load_pack_file` reads any file under `.mason/prompts/` from the base commit with the pack size cap; a missing, empty or oversized step file fails the step with the file named, and never runs the built-in prompt.
- `round-reason.txt` is written beside `feedback.txt` when a step is sent back (`fix`, or `conflict`); `pack_candidates` picks step file, else `<reason>.md`, then `develop.md`, then the built-in prompt.
- The editor schema shows `prompt` for agent steps after `agent`; `mason definition check` reports a missing file beside the definition and exits 1.
- Tests: `crates/daemon/tests/prompt_packs.rs`, unit tests, `scripts/exit/s294.sh`.
