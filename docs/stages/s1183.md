# s1183: retry the integration-branch cleanup

Summary: The coordinator now deletes a finished batch's integration branch on every pass, so one failed post-batch cleanup no longer leaves it behind.

## Cause

The cleanup after a batch (`landing.rs`) runs once and ignored git errors, e.g. an index.lock in the slot worktree. Only the first pass after a daemon start swept leftovers, so `landing_crash` saw `mason/int/scratch/b3` stay for its whole poll.

## Change

`release_finished_integration` runs each coordinator pass for batches with `finished_at` set; errors are logged and retried. The old cleanup now logs its failures. The `landing_crash` failure message lists worktrees and branches. `landing.rs` is protected: owner approval needed.
