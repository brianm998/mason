# s1100: exit scripts follow the signal-based Compose settle

Summary: The s1026 and s1068 exit scripts now check the signal-based Compose settle instead of the removed quiet-window text, so exit-scripts shard 6 no longer fails on it.

## Cause

`CI/exit-scripts (ubuntu-latest, 6)` was red twice (run 45581279465): `FAILED scripts: scripts/exit/s1026.sh` with no output. Commit 04457f150 (decision 1026) rewrote Compose `settle()` (`clients/compose/app/src/main/kotlin/mason/monitor/Tool.kt:61-80`) and removed the quiet-window fallback. `scripts/exit/s1026.sh:11-12` still grepped for `quiet exit, views at` and `QUIET_TICKS`, and `grep -q` under `set -e` fails silently.

`scripts/exit/s1068.sh` held the same two stale greps, and a third for `val reached = model.lastViewSeq >= target`, which the same rewrite replaced with `val covered = model.lastViewSeq >= seq`.

## Change

The stale greps now check what `settle()` does today: the view-seq test, the "Settled is a signal" comment and the `applied up to` timeout message. No client or crate code changed.

## Tests

`scripts/exit/s1100.sh` runs both repaired scripts and refuses a return of the removed strings.
