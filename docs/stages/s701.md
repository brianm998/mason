# s701 — CI-watch tickets quote the error; skipped jobs stop being red

Summary: CI-watch tickets now quote the failing step's error lines (`error_excerpt`) instead of the log tail, and a job whose latest run is `skipped` or `neutral` is no longer red.

- `mason_core::ci_watch::error_excerpt` cuts the full log at the first `##[error]` (or the post-job section), keeps failure-marker lines with two lines of context, strips timestamps and ANSI codes and names the `Run <cmd>` step. `file_task` uses it, falling back to the tail.
- `step` resets a job's state on `skipped`/`neutral`; `cancelled` is unchanged. A job stuck red clears on the next develop run that skips it (`step` reads runs newer than `last_run`); no one-time re-read was added.

Not verified: the fixtures under `crates/core/tests/fixtures/ci_logs/` are hand-trimmed imitations of the real logs (no network), not downloads. The exit test on the owner's machine (star TestFlight job clearing) was not run.
