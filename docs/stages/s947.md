# s947: a floor build no GitHub runner takes is built on this Mac

Summary: When no GitHub runner picks up a landing's floor build within the outage limit, the build now runs on this Mac instead of failing the batch with a service error.

**Cause.** `build_suites` (crates/daemon/src/landing.rs) sends a floor build to GitHub when the suite names a non-macOS runner. `check_through_outage` retries a "no runner picked up" error for 30 minutes and then the batch fails with "the build of the batch gave no result". Tasks #741, #729 and #736 each hit it three times in a row, because nothing changed between tries.

**Change.** After the outage limit, the same build is run once with no placement, so it builds here, and the notes say so. A build is the same on any machine; only its result matters to the floor.
