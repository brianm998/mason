# s46: Count tile double-click

Summary: double-clicking a non-zero count tile reveals its sidebar section and, if it holds exactly one task, opens that task. Single click is unchanged.

## Built
- Both models: `tileClicked`, `revealAndOpenIfOne`, `tileTooltip`. Views call only these.
- Swift `CountTile` reads `NSApp.currentEvent?.clickCount`; Compose `CountTile` counts presses in a `pointerInput`.
- Scroll made more reliable (Swift: scroll on next main-queue turn; Compose: clear target before animating).
- `[feature.tile-double-click]` in `clients/features.toml`. Decision record 0024.

## Exit test
Core unit tests in both clients: one task opens; three/two tasks expand and scroll, page unchanged; zero changes nothing; search-hidden lone task opens; disconnected does nothing; tooltip.

## Not done / not verified
- No UI-level check against a real daemon was run, and no `tile` tool command or conformance "open" action was added. The SwiftUI `clickCount` and the Compose pointer gesture, and whether the header really ends at the top of the sidebar, were not checked by hand or automatically.
- Gradle core tests were not run unless stated in the submission.
