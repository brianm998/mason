# s665: changed files outside a crate's src/ narrow to the test targets that read them

Summary: The test-target picker no longer runs the whole workspace for a data, workflow, support or manifest change: only the root `Cargo.toml`/`Cargo.lock`, the toolchain file, `.cargo/` and paths the suite's own command names still do, and the reply and test-step note now say which path did it.

**Change.** `affected::select` takes the suite's command text (`run`, `build`, `dev_command`, `dev_build`). `Pick::All { because }` carries the path. Rules: a package's `Cargo.toml` or `build.rs` runs that package whole plus every integration target of its dependents; a non-target file under `tests/` selects that package's targets whose text names its directory or stem (a `.rs` file) or file name; any other path selects targets in any package whose text contains the path or file name, and a package whose `build.rs` names it runs whole as above. A path nothing names selects nothing of its own (the smoke set still runs; the landing batch runs everything). `scope::narrow_for` now returns `Result<Narrow, String>` with the reason; `run_check` prints "runs whole because ..." and the test step logs the same.

**Test changed on purpose.** `support_cargo_and_build_files_select_everything` is rewritten as `only_root_cargo_files_the_toolchain_and_named_scripts_select_everything` plus new tests for each rule: this is the intended behaviour change, not a weakened test. `Makefile` alone now selects nothing instead of everything.

**Trust.** `suites.rs` is in `PROTECTED`; the edit there is only the narrowing call's extra argument and the text of the log line for "runs whole" (no verdict logic). It waits for the owner's approval.

**Not verified.** The `suites.rs` message goes to stderr, not into the step's recorded note (the existing code logged it there too). Substring matching of file names is generous: a short file name appearing in unrelated text includes that target (safe direction). The scoped `run_check` of the whole daemon crate timed out on a busy machine; only the unit tests of `affected` and `scope` and the exit script were run.
