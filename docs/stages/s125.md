# s125: mascot status pictures and empty screens

Summary: Home shows a 96 pt mascot picture beside the status line (not_connected, needs_attention, developing, otherwise all_clear; no_tasks at 120 pt with an Add task button), an empty Landing queue shows nothing_landing (desktop and phone), an empty Health findings list shows all_clear, and a sidebar search with no matches shows no_results with "Nothing matched.", in both desktop clients.

## What changed

- `MonitorCore/MascotChoice.swift` and `core/.../MascotChoice.kt`: `homeMascot` picks the picture from connected, attention, active models and the stage rows only; `searchMatchesNothing` and the shared text.
- Views: `MascotPicture` (hidden from accessibility, `contentDescription = null`, never tinted, size = token x `theme.scale`; an unknown id draws nothing). Phone `LandingScreen` uses `@ScaledMetric`.
- `clients/tokens.toml`: `mascot_status = 96`, `mascot_empty = 120`.
- `clients/features.toml`: `mascot-status-pictures`, done in both (adds a feature only).
- Status text, `Items.swift` and `Items.kt` are unchanged. The inline "Nothing is landing." and "Nothing is running." on Home stay text only.
