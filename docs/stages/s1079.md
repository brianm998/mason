# s1079: macOS exit-script runner no longer hangs on the watcher's sleep

Summary: The exit-script runner kills the limit watcher's sleep when a script ends, so the macOS legs no longer wait out the whole job limit.

## Cause

Run 45361042086: `s00 OK` at 09:28:56, then nothing until the job was cancelled at 10:26:30. macOS has no timeout(1), so `scripts/run-exit-scripts.sh:71-79` starts a watcher subshell and later runs `kill "$watcher"`, which kills only the subshell. Its `sleep 3600` child keeps the stdout pipe into `tee "$log"` (line 106) open until the limit passes.

## Change

Before killing the watcher, `pkill -P "$watcher"` kills its sleep. The timeout(1) branch and the ci.yml values are unchanged.

## Tests

`scripts/exit/s1079.sh` runs the runner with no timeout on PATH and asserts it passes and leaves no `sleep 977`. The change is hypothesis-checked by the next macOS run.
