# s447: monitor-tool snapshots at iPad landscape sizes

Summary: `monitor-tool snapshot --ipad` renders the monitor offscreen at 1366×1024 and 1180×820 (scale 2, light and dark), and tests can check the top bar fits an iPad width.

## What changed

- `MonitorUI/IPadSnapshot.swift`: sizes, `ImageRenderer` rendering, PNG writing (size in each file name, e.g. `home-1366x1024-dark.png`), `topBarLeastWidth`.
- `MonitorTool`: `snapshot --ipad --port P --out DIR` writes home and task pages: four images per size.
- `IPadSnapshotTests`: dimensions at both sizes and top bar fit. Exit script `scripts/exit/s447.sh`.

## Not verified

Nothing was built or run in this session, so no image is attached to this note; the sidebar and main pane fit are not measured (only the top bar). `ImageRenderer` may not draw AppKit-backed controls; the Mac `shot` uses `cacheDisplay` for that reason.
