# s210: run_check can be scoped while developing; the test step stays whole

Summary: `run_check` takes optional `tests`, `packages` and `changed`, a suite may name a `dev_command`/`dev_build` with `{packages}` (the touched crates and their dependents from `cargo metadata`), the develop prompt tells agents to iterate scoped and run one full check at most, and the test step still runs the whole suite.

Task #265. Decision 0205.
