# Stage 594: launch-frozen is scoped to the daemon

Summary: `launch-frozen` now reads only the step-host launches under the daemon's own hosts directory, with the threshold a per-daemon config field, so test daemons in one process no longer see each other's launches.

The step-host launcher registry tags each launch with its hosts root; `launching_under(dir)` filters by it. `alerts_now` and `health.rs` use it. `DaemonConfig::launch_frozen` (default 120 s, `MASON_LAUNCH_FROZEN_MS` read in `DaemonConfig::new`) replaces the env read in `alerts_now`.
