# s328: Monitor home shows the running daemon's commit

Summary: Home in both monitors shows a selectable line with masond's short commit (from the welcome), how far behind develop it is, and the monitor's own commit, with full hashes in the tooltip.

The line comes from `versionLine` / `versionTip` in the Swift and Compose models. `dev` reads
"unversioned build". The behind count is parsed from the daemon's own sentence
("N commits behind develop") because `UpdateInfo` has no numeric field.

New feature row `home-daemon-version` in `clients/features.toml` (a PROTECTED file, "gates:
client parity") is marked done in both clients and waits for the owner's approval.

Not verified: the Swift and Kotlin tests and the rendered layout and tooltips were not run by
me. The regex depends on the daemon's wording (`crates/daemon/src/update.rs`).
