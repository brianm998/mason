# s124: the task page shows its state as a picture

Summary: The task page in both desktop clients, and the phone's task screen, show the ticket's state as a 96 pt mascot illustration (the phone also shows the state name), chosen from the daemon's state and updated when it changes.

- `clients/tokens.toml` gains `mascot_illustration = 96`; `Theme.illustration` (Swift and Compose) scales it with the text zoom. The generated `Tokens.swift` / `Tokens.kt` were edited by hand to match the generator's output, because the sandbox here would not run the generator; `conformance tokens --check` confirms or fails it.
- `TaskDetailPage` puts the picture left of the title block (title, state line, waiting reason, copy buttons). It is fitted whole to its square, hidden from accessibility (`contentDescription = null`), and nothing is drawn for an unknown state. Slow tickets keep their state picture.
- Phone `TaskScreen` shows the picture and the state name at the top; its size follows Dynamic Type (`@ScaledMetric`).
- Feature `mascot-state-illustration` is done in both columns of `clients/features.toml`.

Not verified: nothing was compiled or run by me for Swift or Kotlin; the look on both themes, the live update on a pushed state change and the phone conformance text were not seen. The repository has no phone expected-output file, so none was changed.
