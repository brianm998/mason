# s605: exit-script grep options go before the `--` separator

Summary: `scripts/exit/s576.sh` now puts `--exclude` before `--`, so grep no longer reports a missing file `--exclude=s576.sh` and the self-exclusion applies; `s605.sh` guards the whole class.

Cause: `scripts/exit/s576.sh:6` on origin/develop had `--exclude=s576.sh` after `--`, so grep read it as a file operand. The check still passed because s576's text does not match its own pattern.
