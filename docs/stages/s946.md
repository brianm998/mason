# s946: a red base names the compiler's first error

Summary: The landing message "the base does not build" now carries the compiler's first error line, so repeated identical landing failures show their real cause.

Nine landing failures read identically ("swift-clients: the base does not build") because the message kept only the suite line. `base_builds` in `crates/daemon/src/landing.rs` now appends the first line containing `error` from the build tail. Behaviour is otherwise unchanged: a red base still blames nobody and lands nothing.
