# s984: the Failed tile opens a Failed page

Summary: A double click on the Failed tile now opens the lone failed task, or a Failed page listing every failed task (with "N of M" when capped); the phone tile tap and `mason://section/failed` do the same.

`failed` is added to `Page.sectionNames` (Swift and Compose) with the title "Failed". `StageRows` draws the sidebar's rows; a capped section page shows the sidebar's count text. A double click on Failed with no rows does nothing. `clients/features.toml` (protected) only has `failed` added to the `section-detail-pages` description; it needs the owner's approval.

Not verified: no Swift or Gradle test was run in this shell; the tests run via run_check. The Failed row shows its step and time as other rows do; Retry/Cancel are not added to the page (opening the task is enough). The Compose desktop and Android screens were not rendered.
