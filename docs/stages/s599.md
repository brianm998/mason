# s599: the smoke list named a test target that does not exist

Summary: The smoke list now runs `-p mason-daemon --test it` instead of the missing `landing_floor` target, and an exit test checks that every `--test` name in the list is a real target.

**Cause.** `.mason/smoke-tests.txt:11` said `--test landing_floor`, but `landing_floor` is a module of the `it` executable (`crates/daemon/tests/it/main.rs` declares `mod landing_floor;`), so cargo failed the build.

**Change.** The line names `it`. The smoke parser (`affected::add_smoke`) only accepts `-p`, `--lib`, `--bins`, `--doc` and `--test T`, so a name filter is not possible.

**Tests.** `scripts/exit/s599.sh` checks the file layout only.
