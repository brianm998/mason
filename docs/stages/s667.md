# s667: the CI watch sees timed-out jobs

Summary: The base-branch CI watch now reads a GitHub job time-out as its own condition, files "exceeds its time limit" after `agreement` runs, and stops saying "waiting for a newer run" when newer runs timed out.

See decision 0660. Changes: `crates/core/src/ci_watch.rs` (rules, `timeouts`, `held_text_timeouts`),
`crates/daemon/src/ci_watch.rs` (`job_conclusion`, filing, status, state), `crates/adapters/src/github.rs`
(`job_annotations`), `crates/cli/src/main.rs` (status line). Exit test: `scripts/exit/s667.sh`.
Not verified: the live GitHub annotations endpoint (see the decision).
