# s1044: Windows build of the `retrying` test helper

Summary: The `retrying` test helper in remote.rs now sets the hook's executable bit only under `#[cfg(unix)]`, so the Windows CI build compiles again.

## Cause

`retrying` called `std::os::unix::fs::PermissionsExt` and `from_mode` unconditionally (E0433, E0599 on Windows).

## Change

Gated the call like `reject_first`. Test code only.
