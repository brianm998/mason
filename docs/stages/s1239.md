# s1239: onboard builds on Windows

Summary: `mason-onboard` used `std::os::unix` without a gate, which broke `CI/windows`. It now uses `mason_platform::fs::{is_executable, set_executable}`.

## Change

`crates/onboard/Cargo.toml` (new `mason-platform` dependency), `Cargo.lock`, `src/questions.rs`, `src/lib.rs` tests. The daemon was checked for unix-only uses of onboard items. See decision 1229.

## Not verified

The Windows build was not run here. Onboard tests that write a `claude` file are not expected to pass on Windows yet, since a Windows runnable needs a .exe name.
