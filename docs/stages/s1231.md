# s1231: stuck:wait ignores check holders' run length

**Cause.** `judge` (`crates/core/src/health.rs`) bounded a pool wait by position x longest holder
run. A `#N check` lease is one job of a full-CI check that runs for hours, so the bound was far
too short (#1111: 747 min waited, bound 120 min).

**What exists.** `HolderFact.check`, set from `is_check_lease` (`sched.rs`) over the holders in
`publish_waits`. A check holder gives no bound; the quiet branch is unchanged, and a progressing
wait becomes the `stuck:aged-wait` Note. Tests: `check_holders_give_no_run_length_bound`,
`is_check_lease_matches_only_agent_check_labels`.

**Not done.** Using the lease's expected duration (the ledger keeps it only on waiting requests).

**Trust.** `crates/daemon/src/sched.rs` and `scripts/exit/s1231.sh` are PROTECTED; owner approval.
