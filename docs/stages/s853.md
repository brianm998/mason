# s853: the abandoned-run test polls its waiting request

Summary: The abandoned-run test keeps its waiting request polled through every wait and fails at once, naming the explain text, if the request is dropped instead of sitting out the 900 s floor.

**Cause (hypothesis).** `next` was only polled in the final wait; the broker reaps an unpolled pid-less waiter after 120 s, after which it is `Gone` forever. On a loaded runner the earlier waits could exceed that.

**Change.** Test only: poll `next` in the intermediate waits; the final wait is a `wait_poll` that maps Gone to a failure and records the last explain. No daemon code, constant or gate changed.

**Not verified.** That the reap is the actual cause; a future red will now say whether the request was Gone or still Waiting.
