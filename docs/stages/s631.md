# s631: offscreen Swift test hosts get a window

Summary: The three offscreen body-count Swift suites now host their views in a never-ordered NSWindow so CI/monitor-swift stops failing on zero body evaluations.

## Cause
Hypothesis: a bare NSHostingView with no window evaluates no bodies on macos-latest, so `before > 0` fails.

## Change
The `host` helper in RowRedrawTests, FollowOnlyWhatTheyShowTests and LazySidebarTests puts the view in a retained, never-ordered window. No assertion changed.

## Tests
scripts/exit/s631.sh (source checks; runs the three suites on macOS).

## Not verified
The hypothesis is not confirmed on macos-latest, and the failing test names were not in the log tail.
