# s557: nonisolated approval priority constants

Summary: `MonitorModel.approvalPriorities` and `defaultApprovalPriority` are `nonisolated`, so using the default as a default argument of `approve` no longer warns under Swift 6 rules; the plain-approve test now pins the sent priority to "normal".

Changed `Model.swift` only on those two immutable Sendable constants. Language mode and call sites are unchanged. Not verified: other Swift 6 warnings in MonitorCore beyond what the test run's build output showed.
