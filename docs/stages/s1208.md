# s1208: a skip reloads the project's pipeline before judging an unstarted task

Summary: `CI/exit-scripts-macos (3)` failed in s1007 with "there is no step `review`". The skip handler now reloads the project's definition first when the task has not started. See decision 1198.

## Cause

`suites::skip` judges a task with an empty pinned def by `current_def(project)`, which is the built-in pipeline (no `review` step) until the project's definition has loaded. s1007 only waits for `status`, so on a slow runner it skipped too early.

## Change

`skip_task` in `crates/daemon/src/http.rs` calls `reload_definition` for an unstarted task before `suites::skip`. The existing test `a_skip_of_a_step_that_is_not_the_test_step_is_refused` covers the refusal. `scripts/exit/s1208.sh` runs s1007 five times.
