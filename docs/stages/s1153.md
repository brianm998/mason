# s1153: skills for agents, exported from the base commit (#1140)

Summary: A project's Agent Skills in `.mason/skills/` on its base commit are given to every Claude session as a `mason` plugin; the worktree cannot add or change them, `[agent] user_skills = false` keeps the owner's out, and `mason task show` lists the ones a run called.

## Using it

Put `.mason/skills/<name>/SKILL.md` (frontmatter `name` and `description`, then the body, with any
reference files beside it) on the base branch. Sessions list it as `mason:<name>`. To keep the
owner's user-level skills out of a project's sessions, add to its project file:

```toml
[agent]
user_skills = false
```

## Changes

- `crates/adapters/src/skills.rs`: writes the plugin, works out what to turn off, and holds the
  guard's policy. `claude.rs` adds `Skill`, `--plugin-dir`, the settings keys and the hook.
- `crates/daemon/src/skills.rs`: reads the base commit; records each run's `Skill` calls.
- `mason hook skill --policy <file>`; `AgentEvent::Skill`; `[agent] user_skills`; `fake-claude`
  lists its plugin directories' skills in its init event.
- No skill was added to any project. Splitting a review pack into skills is a later task.

How the CLI loads skills, and why each setting is there, is in decision 1142.

## Verified

- Claude Code 2.1.330 with a temporary `HOME` against a scripted API on 127.0.0.1: the loading
  behavior listed in decision 1142, and the built `mason hook skill` registered as the adapter
  writes it: it let a plugin skill and a user skill through and refused a working directory's.
- `scripts/exit/s1153-real.sh` (the real CLI's init event lists only the plugin's skill).
- `scripts/exit/s1153.sh`: the unit tests, and a fixture project run by the daemon with the
  scripted agent.

## Not verified

- No real model chose or followed a skill; every call was scripted.
- The owner's real `~/.claude` (claude.ai synced skills, installed plugins) and a real
  `enabledPlugins: false` from `--settings` were not exercised.
- Agent steps under an OS sandbox, and Windows.
