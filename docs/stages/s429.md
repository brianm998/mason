# s429: faster landing for a backlog with its testing skipped

Summary: two fixes for landing a batch of tasks whose testing the owner skipped. A third change ships in the same push.
- The dropped-line audit reads the files a task changed only once a landed line is missing from its own file.
- A batch whose every task had its test step skipped is rebuilt, not re-tested, when the base moves while it verifies.
- The Swift monitor's sockets accept messages up to 64 MiB.

## Why

On 2026-11-15 the owner skipped testing for about 58 MASON tasks so they could land, to be tested later in one full run.
- **Batch #262** held only #415 and took 48 minutes. An unrelated push moved develop while it verified, and the re-check after a moved base ran `cargo test --workspace` in full: the only full run that batch got, with 39 tasks waiting behind it.
- **The pre-queue audit** was slow. s415 made the audit read every file a task changed after each merge of the base, one `git show` per file, whether or not any line was missing. #320's branch has 23 such merges, which meant about 3,000 reads, roughly 80 seconds at that hour's load. About 13 land steps sat in that audit before queueing.
- **The monitor** could not connect. URLSession refuses a WebSocket message over 1 MiB by default, and the daemon's snapshot had reached 1.08 MiB.

## What changed

- `crates/landing/src/audit.rs`: `unkept_or_moved` takes `moved_to` as a function. It is called, and those files read, the first time a line is missing from its own file, and at most once per merge audited.
- `crates/daemon/src/landing.rs`: `tests_skipped` is true when every task in the batch has an open `step:<test step>` debt. Then a passing rebuild after a moved base lands the batch without the re-test.
- `clients/swift/Sources/MonitorCore/Reconnect.swift` and `Pairing.swift`: `maximumMessageSize = 64 MiB`.
- Tests:
  - `other_files_are_not_listed_or_read_while_every_line_is_in_its_own` (unit).
  - `a_batch_whose_testing_was_skipped_is_rebuilt_but_not_retested_when_the_base_moves` (`crates/daemon/tests/landing.rs`). It fails without the change.

## Not loosened

A batch with even one task whose testing was not skipped is re-tested as before. The skip's debt stays open, to be paid by the full run on develop.
