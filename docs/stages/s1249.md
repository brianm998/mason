# s1249: Windows build of the cli init test

Summary: `crates/cli/tests/init.rs` is gated with `#![cfg(unix)]`, so `cargo build --workspace --all-targets` compiles on windows-2022 again.

## Cause

The fixture calls `std::os::unix::fs::PermissionsExt::from_mode` (init.rs:53) to make fake agent binaries executable. `std::os::unix` does not exist on Windows, so the build stops with E0433 and CI/windows is red on develop (#1256).

## Change

One inner attribute and a comment in `crates/cli/tests/init.rs`; no test body changed. See decision 1239.

## Verification

On Unix the same tests run. On Windows the target is an empty crate; the windows CI job confirms the build.
