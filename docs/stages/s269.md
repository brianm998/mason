# s269: home shows the project and title of each compiling task

Summary: Home's Compilation section now reads `#294 (mason) - Known red ledger record a test failure... - for 5 min` for each task holding a `compile` slot, in both the Swift and Compose monitors.

Decision 0264 records the choices.

**What changed.**
- `schemas/mason.proto`: `CompileHolder` gains `project = 6` and `title = 7` (empty for an interactive caller, a slot held outside the queue, or a task the store no longer has). Swift bindings regenerated with `protoc`; Kotlin's are generated by the Gradle build.
- `crates/daemon/src/views.rs`: `home()` fills both fields from the store's task row, by id, so a holder from a project home is not filtered to is still named. `Broker::compilation()` only sets empty defaults.
- `Format.shortTitle` / `Format.compileHolder` in both cores (limit 40, cut at a word boundary when one lies in the second half, "..." only when cut) and both `CompilationSection`s; the Swift row has a help tooltip with the full title.
- Tests: `home_compile_holders_carry_the_tasks_project_and_full_title` (daemon), `CompileHolderFormatTests.swift`, `CompileHolderFormatTest.kt` (same cases both sides).
