# s885: landing_floor github test world lacks the base workflow

Summary: The floor-on-GitHub test world now carries `.github/workflows/mason-run.yml` on its base, as the real repo does, so `a_floor_set_to_github_goes_there` reaches the fake GitHub.

## Cause
`remote::snapshot` (crates/daemon/src/remote.rs:573-575) fails when `origin/main` has no `.github/workflows/mason-run.yml`. The scratch world in `floor_github_world` (crates/daemon/tests/it/landing_floor.rs) had none, so no connection was ever made.

## Change
`floor_github_world` pushes a minimal workflow with no `push` trigger. Nothing in src/ changes.
