# s446: one universal iOS app project, built with `make ios`

Summary: an XcodeGen spec builds one universal iPhone and iPad app from `clients/swift` with `make ios`, picking the phone or iPad root by size class, after the first real iOS compile fixes.

## What changed

- `clients/swift/ios/project.yml`: one app target, iOS 17, `TARGETED_DEVICE_FAMILY = 1,2`, linking `MonitorCore`, `MonitorPhone`, `MonitorUI`, `MasonMascot`. Bundle id from `MASON_IOS_BUNDLE_ID` (default `dev.mason.ios`), `DEVELOPMENT_TEAM` empty. The generated `.xcodeproj` is gitignored.
- `Package.swift`: `MasonMascot` is now a library product.
- Asset catalog with the single 1024 px `AppIcon` (moved from `AppIcon-1024.png`); `Info.plist` with iPad landscape, iPhone portrait, `ITSAppUsesNonExemptEncryption = false`, `remote-notification`, local-network and Bonjour keys; entitlements with `aps-environment = development`.
- `MasonIOSApp.swift`: `AppRoot` picks `RootView` (regular) or `PhoneRootView` (compact) through `RootChoice.choose` (MonitorCore, pure, three unit tests).
- `make ios` runs XcodeGen then `xcodebuild build` for `generic/platform=iOS Simulator` with `CODE_SIGNING_ALLOWED=NO`; it fails naming `brew install xcodegen` if XcodeGen is missing.
- Compile fixes from the first real iOS build: `Discovery.defaultDataDir` (no `homeDirectoryForCurrentUser` on iOS) and iOS stand-ins for the Mac-only `.link` button and `.checkbox` toggle styles (`MonitorUI/IOSStyles.swift`). `MonitorCore` and `MonitorPhone` needed nothing else.
- `scripts/exit/s446.sh` (a new exit script, so a protected path: owner approval) runs `make ios`; it skips with a stated reason without Xcode or XcodeGen.

## Not verified

- Only a simulator build was made, with the package checkouts copied from another worktree because the network is closed here. Nothing was run, no simulator test, no archive or signing, no TestFlight.
- The iPad root is the Mac `RootView`, not checked for fit on an iPad; the layout is a later task. The `.link`/`.checkbox` stand-ins change how those controls look on iOS.
- `swift test` and the whole-workspace checks are left to the pipeline's tests check.
