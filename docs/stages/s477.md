# Stage 477: shorter real-time waits in the daemon tests

- `tests/holds.rs`, kill-and-restart test: after the restart has been shown to keep the hold in
  force and to start nothing during it, the test moves the stored hold's end to two seconds from
  now instead of waiting out the rest of its 120 s. The first test's reset is 8 s, not 14 s.
  Assertions are unchanged. Production defaults are unchanged.
- `tests/crash.rs`, `tests/landing_crash.rs`: read, not changed. They kill and restart a real
  daemon at each of a list of points; their time is the restarts and git work, and no production
  timeout is waited on. Their one fixed sleep (6 s in `crash.rs`, "finished while down") covers an
  agent finishing with nobody listening and has no event to wait for.
- Not done: `landing_modes`, `host`, `landing`, `git_blips`, `scheduling`, `ci_infra`,
  `definitions`, `update`. I did not read them.
