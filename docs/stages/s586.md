# s586: the monitor's notification bar can be dismissed, scrolls after three rows, and resizes

Summary: Every notification row has a dismiss X, the bar shows at most three rows before a scroll view with a draggable, adjustable handle, and a "Show hidden notifications (N)" button brings dismissed rows back.

**What changed.** `MonitorCore/Notifications.swift` builds the list of rows with stable keys (client id, banner kind+project+mode+session+text, issue number) and keeps dismissed keys and the chosen height in `Preferences`, pruned like the pause collapse. `BannersView` renders that list, measures the rows, scrolls after three, and has the handle and the button. The pause collapse control is now `chevron.up`.

**Not verified.** Written without being able to build locally (the shared build queue refuses direct `swift build`); the offscreen UI tests, their accessibility-tree lookups, the cursor on macOS, dragging on iPhone and VoiceOver adjust were not run by hand.
