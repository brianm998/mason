# s1212: command-guard test on Windows

**Cause.** The s1154 fix made the guard assertion in `every_session_is_given_the_command_guard`
platform-correct but left the `hook edit` expectation hard-coded as `'/bin/mason{EXE}' hook edit`.
On Windows `with_file_name` yields `/bin\mason.exe`, so `CI/windows` stayed red.

**Change.** The edit-hook expectation is built from the same `mason` path as the guard assertion.
No production code changes.

**Exit test.** `scripts/exit/s1212.sh`.
