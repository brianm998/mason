# s474: dev and test builds use line tables only, and none for dependencies

Summary: The workspace `[profile.dev]` now sets `debug = "line-tables-only"` and `[profile.dev.package."*"] debug = false`, which cut the target dir of a cold workspace test build by about 20% and the wall time by about 7%.

Measured on the same commit, cold target dir each, `cargo test --workspace --no-run`, on a machine shared with the pipeline (so times are noisy):

| | wall | user CPU | sys CPU | target dir |
|---|---|---|---|---|
| before (`debug = 2`) | 404.5 s | 1426 s | 743 s | 7.26 GiB (7612352 KiB) |
| after (line tables, none for deps) | 377.7 s | 1350 s | 936 s | 5.82 GiB (6107056 KiB) |

Size is the solid number (-19.8%). Wall and user CPU improved by 7% and 5%; sys CPU went up, and with one run each on a busy machine I cannot say the time difference is real. Not verified: link time alone, repeated runs, incremental rebuilds, and the test suite itself (left to the test step). The `release` profile is untouched. `CARGO_PROFILE_DEV_DEBUG=2` restores full info; see docs/self-hosting.md.
