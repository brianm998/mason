# s266: shell steps, askpass and tool lookup on Windows

Summary: Project commands now run through one shell function (`sh` on Unix, Git for Windows' bash on Windows with a clear error when absent), the Windows askpass helper is `mason-askpass.cmd`, and `mason doctor` reports the shell.

Done: `crates/platform/src/shell.rs` with discovery taking injected inputs (unit-tested); `jobs.rs` and `adapters::fakehost::run_command` use it; `ssh_keys::askpass_file_name`; `packaging/mason-askpass.cmd`; doctor line.

Not verified: nothing was run on Windows. The `.cmd` dialog and the Git Bash discovery against a real install are untested; the registry is not consulted. Path conversion is provided (`to_shell_path`) but call sites that embed paths in commands were not audited. Other `sh` users (landing, update, schedule, introspect, basecheck, cli init) and the release tarball's `INSTALL` list are unchanged.
