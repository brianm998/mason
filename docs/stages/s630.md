# s630: s602 failed on the CI exit-scripts shard 4/6

Summary: The s602 exit test now clears `MASON_EXIT_SHARD` before running its scratch runner, so it no longer fails with "expected exit 1, got 0" on CI shard 4/6; s630 checks it under that shard.

**Cause.** CI exports `MASON_EXIT_SHARD=4/6` (`.github/workflows/ci.yml:105`, `:152`). `scripts/exit/s602.sh` runs the runner in a scratch repo with three fake scripts, and the runner (`scripts/run-exit-scripts.sh:13,17`) inherited the shard, so none of the three ran and it exited 0.

**Change.** `scripts/exit/s602.sh` starts with `unset MASON_EXIT_SHARD`. The runner is unchanged.

**Tests.** `scripts/exit/s630.sh`.
