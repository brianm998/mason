# s671: s634.sh feeds an ERE to grep

Summary: `scripts/exit/s634.sh` now rewrites `(?:` to `(` in the suite's `pass_regex` before `grep -E`, which fixes the red CI/exit-scripts job.

**Cause** `pass_regex` in `.mason/mason.toml` uses `(?:`, which POSIX ERE rejects, so both pass checks in s634.sh failed. The cause is inferred from reading the script; the log tail did not show the failing line.

**Change** One parameter expansion in s634.sh (`ere=${pass//'(?:'/'('}`); the toml is untouched. `scripts/exit/s671.sh` checks the translated regex against sample lines without cargo.

**Run** `bash scripts/exit/s671.sh` only; s634.sh itself runs cargo and was not run here.
