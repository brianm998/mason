# s1078: exit-scripts fallback watcher no longer hangs the runner (#1088)

Summary: A new exit test checks that the macOS fallback in run-exit-scripts.sh runs one exit script after another, reports failures, and leaves no watcher `sleep` behind.

## Cause

`scripts/run-exit-scripts.sh` started `( sleep "$limit"; ... ) &` with inherited stdout; `kill "$watcher"` left the `sleep` alive holding the pipe to `tee`.

## Change

- The runner fix landed first: `pkill -P "$watcher"` as s1079 (decision 1068) and the watcher's /dev/null stdio as s1076 (decision 1065). This branch no longer changes the runner.
- `scripts/exit/s1078.sh` runs the runner without timeout(1) and checks that it finishes, reports PASS/FAIL, and leaves no `sleep` behind.
