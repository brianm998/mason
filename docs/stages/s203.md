# s203: monitor top bar stacks its groups so it fits a narrower window

Summary: The monitor top bar stacks home over back/forward, the attention indicator over the project filter, 5-hour over weekly usage and the buttons in a 2x2 grid, and a zero count is drawn gray, in both clients.

What changed
- Daemon `usage.rs`: a subscription account pushes one `top_bar` line per reported main window, shortest first (`five_hour`, then `seven_day`); `*_opus` windows stay on the Usage page. Api-spend, hold and sessions lines are unchanged. `schemas/mason.proto` comment (and the generated Swift copy) updated; the wire format is the same.
- SwiftUI `TopBar.swift` and Compose `TopBar.kt`: the layout of items 1, 2 and 5; every usage line of an account is shown (`topBarUsageLines`). Accessibility ids: `topbar-usage:<account>` on the first line, `topbar-usage:<account>:<n>` (n from 1) on the rest, in both clients. The empty wand cell is an invisible placeholder so mute and voice stay put.
- `tileCountColor` (Components.swift / Components.kt): attention colour if the state wants you, `muted` for a zero count while connected, else `text`; the disconnected dash is unchanged.
- Tests: `crates/daemon/tests/usage.rs` (two lines in order, weekly fuller, one window), `protocol.rs`; `TopBarFitTests.swift` (fit at 1000 pt, colour, lines, offscreen render to `$MASON_TOPBAR_IMAGES` or the temp dir); Compose `TopBarTest.kt`.
- `mason usage` (cli main.rs:2013) already keeps every matching line; `MonitorPhone` lists all `top_bar` lines. Neither was changed.
- Decision: `docs/decisions/0198-top-bar-stacked-groups.md`.

Proposed `clients/features.toml` wording (protected; not edited, no status flipped; owner to approve)
- `feature.top-bar`: "Home over back and forward; attention indicator over the project filter; LLM usage (5-hour over weekly); add task and improve over mute and voice in a 2x2 grid"
- `feature.count-tiles`: "One tile per state, sized to its label, tinted when it wants you, gray number when the count is zero, a dash while disconnected"
- `feature.usage-top-bar`: "The top bar shows the 5-hour and weekly windows per account, 5-hour above weekly (\"claude 5-hour 82%, resets 1 h 10 m\"), else its sessions"

Not verified

- No images were rendered: the Swift render test writes them when run, and there is no Compose offscreen render test at all.
- The Compose layout was never looked at.
