# s46: scripts/gen-*.sh are protected

Summary: Edits to the scripts the daemon runs when changes land (`scripts/gen-*.sh`, today `gen-status.sh`) are held for the owner like the other gates.

Task #12. `Batch::regenerate_status` runs `bash scripts/gen-status.sh` in the integration worktree, but the script was not on `PROTECTED`, so a task could change what the daemon executes. `scripts/gen-*.sh` is now protected and, not being under `ADDED_OK`, a new generator is held by its path too. Adding a file under `scripts/exit/**` is still not held by its path.

## Built
- `crates/daemon/src/protect.rs`: one `PROTECTED` entry; the listed-files test gets the new glob and its near misses; a new test for added `gen-x.sh` (held) versus added `scripts/exit/sNN.sh` (not held).
- `docs/self-hosting.md`: lists `scripts/gen-*.sh` among the gates.
- Decision record `docs/decisions/0024-gen-scripts-protected.md` (the audit of what the daemon runs).

## Exit test
`bash scripts/exit/s46.sh` (a real masond, fake-claude): a task editing `scripts/gen-status.sh` waits for approval naming the file; a task adding only a stage note lands.
