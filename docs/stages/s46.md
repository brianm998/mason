# s46: the plan as a readable document

Summary: Both monitors show a task's plan as readable text (summary, numbered steps, files, criteria) parsed by the daemon into PlanView, with Copy plan and Copy JSON.
Task #16. The daemon parses `plan.json` into `PlanView` (`TaskDetailView.plan_view = 19`); both monitors draw summary, steps, files, criteria and other keys, with Copy plan (Markdown) and Copy JSON. Choices: `docs/decisions/0024-readable-plan-readings.md`.

## Built
- `schemas/mason.proto`: `PlanView`, `PlanExtra`, `plan_view = 19`. `plan = 3` unchanged.
- `crates/daemon/src/plan_view.rs`: pure parser + 11 unit tests (every case in the exit test list, plus a real-size fixture).
- `views.rs`: fills `plan_view`; `plan` still filled. Acceptance gate and prompts untouched.
- Swift: `MonitorCore/PlanText.swift` (copy-as-text, expand rule, marker), `MonitorUI/PlanSection.swift` (layout, `AttributedString(markdown:, .inlineOnlyPreservingWhitespace)`), `monitor-tool task-page`. `mason.pb.swift` regenerated with `scripts/gen-clients.sh` (protoc present).
- Compose: `core/.../PlanText.kt` (same functions plus a small inline `code`/`**bold**` parser), `app/.../ui/PlanSection.kt`.
- `clients/features.toml`: `readable-plan`; `scripts/exit/s46.sh`.
