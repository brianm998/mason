# s128: the sweep no longer files an orphan for a host that is being stopped

Summary: The reconcile sweep skips a running step host the daemon asked to stop within 30 s, so normal step transitions no longer file a false orphan_host; genuinely unstopped hosts are still caught.

Cause (from reading the code; see decision 0114): the stop of a closed step's host takes time, and two sweep passes could land inside it. The healthy-daemon test now reports the kinds and bugs filed.
