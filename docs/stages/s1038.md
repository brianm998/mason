# s1038: the exit-script runner names why a script failed

Summary: scripts/run-exit-scripts.sh now prints a failed script's last 40 lines and marks limit kills `(over N s)` in the `FAILED scripts:` list.

## Cause

Shard 6 (ubuntu-latest) of CI/exit-scripts failed twice at a0f67a2 on s101, s616, s664 and s787. The log tail only lists the names; each script's own output sits far above it. The cause of the four failures is still unknown: the full log of run 45143216377, job `CI/exit-scripts (ubuntu-latest, 6)`, would settle it. s787 is the only one with wall-clock assertions, but that is not shown to be the cause.

## Change

The runner tees each script's output to a temp file and, on failure, prints its last 40 lines after the FAILED line. The four scripts are untouched. Both the runner and scripts/exit are protected: owner approval is needed.

## Tests

scripts/exit/s1038.sh uses MASON_EXIT_DIR and MASON_EXIT_WEIGHTS with fake scripts; no timing assertion.
