# s1096: narrowed parallel test runs pass no --doc

Summary: scripts/test-parallel.py no longer runs doc tests when the cargo command selects targets, and a `--doc` command runs only them, as scripts/test-shard.py does.

## Cause

Cargo refuses `--doc` beside a target selector ("can't mix --doc with other target selecting options"). The report named scripts/test-shard.py, which s1075 had already fixed (see docs/stages/s1075.md). scripts/test-parallel.py still appended `--doc` to every command. A `--doc` command also failed there, because the flag reached the `--no-run` build and was then given twice.

## Change

scripts/test-parallel.py uses the same target-selector set and `--doc` handling as scripts/test-shard.py. No configured command runs it today (`.mason/mason.toml` offers it as an option).

## Tests

scripts/exit/s1075.sh case (e) runs it with a fake cargo: a `--test` selection runs the executable and no doc pass, and a `--doc` selection runs one doc pass and no executable. No timing assertion.

Trust files: scripts/exit/s1075.sh needs owner approval.
