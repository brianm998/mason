# s1174: the Swift monitor shows what runs on each host

Summary: Home has a Hosts section (this Mac, each node, GitHub, each with its tasks as links, their pipeline state and how long), the task page a "Running on" line, and the phone a one-line-per-host version.

## Change

- `MonitorCore/Hosts.swift`: pure helpers (host title, run line, shortened activity, duration, section visibility, the Running on text).
- `MonitorUI/HostsSection.swift`: the section (wide and phone layouts) and the run row; `Pages.swift` places it after Nodes and adds `RunningOnLine` after the CPU line.
- Older daemon: no `hosts` means no section and no Running on line (an empty `running_on` alone cannot be told from absent, so `hosts` is the signal).
- `clients/features.toml`: `home-hosts` recorded as Swift/iOS done, Compose todo. This is a protected file; the entry is needed because the parity gate wants every feature listed, and Compose is out of scope for this task.
