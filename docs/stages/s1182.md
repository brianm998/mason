Summary: Harden the hung-git deadline test against a pid-file race on busy runners.

# s1182

`a_hung_git_is_killed_at_its_deadline` could fail under load because the helper's pid file was
missing or still empty when git was killed. The test now waits for a parsable non-zero pid,
fails with a clear message if none appears, and polls (up to 5 s) for the grandchild to die
instead of checking once. No production code changed.
