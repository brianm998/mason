# s616: doc tests run in their own cargo group

Summary: `affected::render` puts `--doc` in a group of its own, so no cargo invocation mixes `--doc` with `--lib`, `--bins` or `--test`.

Cause: `render` (affected.rs) joined every selector of a package into one group, e.g. `-p leaf --lib --doc`, and cargo refuses that ("can't mix --doc with other target selecting options"). `select` sets the doc flag for a changed lib file with a ``` fence, and smoke lines may name `--doc`.

Change: `render` emits `-p NAME [--lib] [--bins] [--test T]` and then a separate `-p NAME --doc`. `scope::expand` is unchanged; its ` --doc` strip for `--no-run` gives a slightly broader warm-up build.

Tests: `doc_tests_render_in_their_own_group` in affected.rs; exit script `scripts/exit/s616.sh`.
