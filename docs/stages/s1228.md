# s1228: the nightly review proposes lines from repeated owner corrections

Summary: The pipeline review gets a seventh part. `review-facts/corrections.json` gathers the last day's owner retry notes, rejection reasons, answers, blocking review findings and diagnosis notes with task numbers, and groups identical ones across tasks (`repeated`). The prompt tells the agent to merge like corrections and, for one seen on two or more tasks, file one `lesson` finding: a one-line CLAUDE.md, prompt-pack or (once #1137 exists) rule line, quoting the items and naming the tasks. At most 3 per review.
