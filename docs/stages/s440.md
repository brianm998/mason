# s440: top bar fits the minimum width again

Summary: the Swift top bar's busiest-state picture shrinks in a narrow window, so the bar fits the 1000 pt main window minimum again (it needed 1079.6 pt).

## Why

TopBarFitTests failed at the base with 1079.6 pt needed, with or without attention showing, so the attention label was not the cause. The fixed-size picture added by s334 (about 82 pt wide) was.

## What changed

- `clients/swift/Sources/MonitorUI/TopBar.swift`: the picture's frame takes any width up to its side, at the lowest layout priority. The tests and thresholds are unchanged.
- The Compose top bar was not changed.
