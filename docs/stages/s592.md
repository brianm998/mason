# s592: the exit-script runner did not name the script that failed

Summary: The exit-script runner now ends a red run with a `FAILED scripts:` line naming every failing script, so the culprit shows in the last lines of a log; the exit status and shard selection are unchanged.

**Cause.** In `exit-scripts-macos (3)` the log tail ends with `PASS s584` and exit 1. s584 exits 0 when it prints PASS, so an earlier script in shard 3 failed, and its `FAILED:` line is above the truncated tail. That script is not yet identified.

**Change.** `scripts/run-exit-scripts.sh` collects failing names and prints them before `exit $fail`. `scripts/exit/s592.sh` checks this by reading the file. The runner is protected; the owner approved the edit.
