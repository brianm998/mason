# s638: CI/windows daemon test support

Summary: Gate the daemon tests' flock slot support behind cfg(unix) so `cargo build --workspace --all-targets` compiles on Windows.

`crates/daemon/tests/support/slots.rs` uses `nix` and `std::os::unix` (lines 14, 17, 124), which do not exist on Windows. `support/mod.rs` declared it unconditionally, so every test binary with `mod support;` failed. Slots are now unix-only with a no-op `Slot` elsewhere, and `world_slots.rs` is `#![cfg(unix)]`.
