# s1306: the diagnosis card tests answer by label

`diagnose_answer::a_retry_option_retries_with_the_note_and_the_context` and
`diagnose_answer::the_explore_close_and_cancel_options_do_what_they_say` failed on develop at
`3c8b855462`.

Cause: a diagnosis card lists its recommended option first (`recommended_first`,
`crates/daemon/src/diagnose.rs`). The tests' fixture recommends "Cancel the task", so the card
reads Cancel, Retry, Explore, Close, while the tests answered by the numbers of the submitted
order.

Fix: those answers now name the option's label. Test-only; no production code changes.

Exit test: `scripts/exit/s1306.sh`.
