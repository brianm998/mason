# s496: TopBarTest loads Skia in the test JVM

Summary: The Compose test JVM loads Skiko's native library at launcher-session start, so TopBarTest and MascotTest no longer fail with UnsatisfiedLinkError.

Mascot.bitmap decodes PNGs through Skia, and nothing in the test JVM loaded the native library.
A `LauncherSessionListener` (SkiaSession.kt, registered under src/test/resources/META-INF/services)
now calls `Library.staticLoad()`. No assertion changed. See decision 0489.
