# s290: `mason config show` lists the project file's settings

Summary: `mason config show --project P` (and `/projects/P/config`) now ends with the project file's own run settings, after the steps: the timeouts, the agent idle rules, the stall watcher (`cont_after_s`, `kill_after_s`), test reruns, auto retry, diagnosis and priority jump, with the file's path. A zero that turns a rule off reads `0 (off)`.

## Why

On 2026-11-14 star task #170 had to check that MASON watches heavy jobs for stalls before removing starpipe's own watch. It looked for `cont_after`/`kill_after` in `mason config show`, which listed only the definition's step settings, found nothing and asked the owner. The answer "update MASON" brought the same question back: the watcher had been there since 11-11, set in `projects/star.toml` and off by default.

## What changed

- `crates/daemon/src/config.rs`: `ProjectCfg::file_settings`.
- `crates/daemon/src/http.rs`: `project_config` adds `project_file` (`path`, `settings`).
- `crates/cli/src/main.rs`: `config show` prints them under "project file".
- Test: `the_project_files_own_settings_are_listed_with_an_off_zero_named` (unit, `config.rs`).

## Not verified

The monitors do not show the new section.
