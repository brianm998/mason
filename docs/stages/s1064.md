# s1064: project rename names its caller

Summary: `mason project rename` now defaults MASON_AS from USER, so the owner's rename works on a runner where only USER is set.

CI/exit-scripts (ubuntu-latest) failed s965 with `"" is not the owner's identity`. The CLI sent no
identity for rename, while `remote` already defaulted it from USER. s965 also exports USER so the
daemon's owner default and the CLI agree. The Windows type-check (s193) and the feature-parity
check pass at this base, so no change was needed there.
