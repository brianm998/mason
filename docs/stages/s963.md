# s963: a debt whose task branch is deleted can still be proven landed

Summary: A skip debt whose task branch was deleted after landing is now proven landed from the merge on the base branch, so the idle pass and `settle_debts` can pay it instead of leaving it open for ever.

What changed
- `crates/daemon/src/suites.rs`: `debt_landed` falls back to `merged_branch_commit`, which reads the oldest `Merge branch '<branch>'` merge in the base's history and takes its second parent.

Tests: `merged_branch_tests` in `suites.rs`.

Not verified
- Debts with an empty scope or a task that never landed stay open; no data on which of the old debts are which.
