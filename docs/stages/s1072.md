# s1072: gate unix-only shim scripts

Summary: Windows clippy red on develop is fixed by compiling the unix-only CAFFEINATE and XCODEBUILD shim constants only under cfg(unix).

## Cause

Both constants are used only in `write_shims`'s `#[cfg(unix)]` block, so on Windows `-D warnings` turned dead_code into errors.

## Change

`#[cfg(unix)]` on the two constants in `crates/daemon/src/node_run.rs`. No behaviour change on unix.
