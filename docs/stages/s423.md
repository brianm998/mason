# s423: a conflict send-back names the base commits behind it

Summary: A task ejected from a batch for a conflict now gets the base's recent commits on the conflicting files in its feedback, so the agent resolves it in one round.

## Why

Conflict send-backs were 70 for mason and 40 for star (about 0.45 per landed task). Branches drift while they wait, and the feedback only said "bring in the latest base".

## What changed

- `crates/landing/src/batch.rs`: `Ejected::base_changes` lists up to ten base commits since the merge base that touched the conflicting files.
- `crates/daemon/src/landing.rs`: the send-back note includes them.
- Test: `a_task_conflicting_with_the_base_is_ejected` checks the list.
