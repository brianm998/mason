# s476: test debts are paid by a green that skipped quarantined tests

Summary: A suite green at a base with known-red tests skipped is now recorded apart (`suite_skip_green`), `settle_debts` pays a debt from it with the skipped tests named in `how` unless the debt's task touched one of them, and `run_idle_debts` never runs the same scope twice on one tip.

- `run_suite` records a whole, unnarrowed green that skipped quarantined tests; `suite_green` still means the whole suite.
- `settle_debts` and `pay` name the skipped tests in `how`; `mason debt list` already prints `how`.
- The matrix and codec tests were red at the base after Deferred/Undeferred (s325) and are updated to 12 states, 26 matrix events and 28 event kinds.

Not verified: the exit scenario on a real scratch daemon with three debts (covered by the unit-level tests in crates/daemon/tests/testing.rs); that "touched" (a changed line naming the test's last path segment) never misses a rename.
