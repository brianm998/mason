# s643: landing fast-tier tests batch by count

Summary: The skipped-batch fast-tier tests now form their batch by `max_size = 2` with a 20m window and create skip debts before admission, so a slow machine can no longer split the pair.

Cause: the tests used `window = "2s"`, `max_size = 5`. `W::task` does git work between the two admissions, so on a busy machine more than 2 s passed, `left` formed a batch alone and landed, and `sent_back(left)` never appeared. The skip debts were also added after admission.

Fix: `W::task_with` runs a hook before admission; the tests use it for the debts and a count-based batch.
