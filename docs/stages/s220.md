# s220: the Compose monitor connection no longer races its own sessions

Summary: The Compose monitor connection writes hello, subscription and ping on the session's own socket, waits for that socket before the hello, and pings before the stall check, so MonitorCoreTest no longer flakes.

## Built

- `Connection.kt`: per-session `say()` on the session's socket; `onOpen` waits on a latch set after the socket is registered; loop order is replaces, ping if due, stall check; `subscriptionMessage()` extracted, public `sendSubscription()` unchanged in behaviour.

## Not verified

Repeated `scripts/exit/s220.sh` runs were not done by the author beyond the pipeline's test step.
