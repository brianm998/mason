# s1119: a node's jobs start under a long data directory, and a step host's error is heard

Summary: A node names each step host's folder by a 16-character key, so job ids no longer lengthen the socket path; a socket path over 100 characters is refused before a host is started, with its length; the host's own errors go to `host.err` and come back in "step host exited before it was up"; and `mason node doctor` and `mason doctor` check the socket length.

- **Node folders.** `node/hosts/<key>`, where the key is the first 16 hex digits of SHA-256 over `coord\0id\0phase`. The file `name` in the folder holds `<coord>-<id>-<phase>`; the id in `host.kv` is the key. A folder with the old readable name that has a `host.kv` is still used, so a restart onto this build collects a job the old one started. The data directory may now be at most 67 characters (the documented one is 51).
- **Up front.** `spawn_host_within` refuses an over-long socket path without starting anything. The step host keeps the same check.
- **Errors.** The launcher appends the host's standard error to `<dir>/host.err`. On "exited before it was up" the error carries the exit status and the last lines this launch wrote, and is printed in the daemon's log. A node also prints why a job failed.
- **Doctors.** `mason node doctor` has a blocking "socket path" check. `mason doctor` still fails when a short host id does not fit under `<data-dir>/h/`, and now warns when a long one (a check's build with a long suite name) does not, saying how long an id fits.
- **Local hosts** keep their readable ids ([decision 1108](../decisions/1108-short-node-host-folders.md)). They get the up-front check and the doctor's warning.

Two places differ from the task's text. A bad `--cwd` does not make a host exit: the host comes up and records that its command could not start (unchanged), so the test uses a `--stdin` file that is missing, which does end the host early. And the exit test's scratch directory is under `/tmp`, at exactly the documented length: under macOS's `$TMPDIR` a directory with that suffix is already too long for any socket below `node/hosts/`.

Not verified here: a job on a real node (Marmot) or from the documented path itself, which needs that user's home; `mason node doctor` run as a command against a live node daemon (the test judges the same check function with the same path `gather` gives it); the restart onto this build with a host of the old naming still running (the folder choice is unit-tested only); and the host folders on Windows.
