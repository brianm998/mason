# s765: crash test host window

Summary: The kill -9 agent-session crash test now keeps its develop step asleep for 60 s and waits for a running step host before the kill, so a loaded runner cannot close the window.

The agent slept 4 s after its commit; on a busy ubuntu runner the host had exited before the SIGKILL, so no running host remained. Assertions are unchanged; the landing wait is 240 s. The other three red tests (`limits::a_hot_die_...`, `remote::tests::a_skip_while_queued_or_running_...`, `remote::tests::iso_times_and_ref_names`) were not changed: their panic lines were not available, so their cause is still unknown.
