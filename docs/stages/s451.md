## Also fixed
`cached_jwt` (crates/adapter-api/src/apns.rs) matched its cached APNs token on key id and team id only, so two tests in one binary with different keys but the same ids could get the other's token and fail signature verification (`a_push_reaches_owner_devices...` failed under load). The key text is now part of the match.

`every_state_and_event_pair` (crates/engine/tests/matrix.rs) and `every_event_kind_round_trips` (crates/store/src/codec.rs) had been red on develop since s325 (6d69acae) added the Deferred state and the `Deferred`/`Undeferred` events without updating them. The matrix now lists both events and has Approve, Reject, Cancel and TrackerEdited legal from Deferred, as the reducer does. The codec test now expects 28 event kinds. Neither the reducer nor the codec changed.

The daemon tests `an_agent_step_times_out_on_the_original_clock_after_a_restart` and `a_running_steps_cell_gains_tokens_before_it_ends` failed in earlier rounds because of machine load. This change doesn't touch them; they are filed as a proposal.
