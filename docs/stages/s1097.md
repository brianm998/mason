# s1097: test-parallel runs no doc tests for a target selection

Summary: The parallel test runner no longer adds `--doc` to a target selection (`--test x`, `--lib`), which cargo refuses, and a `--doc` command now runs only the doc tests.

As scripts/test-shard.py has done since #1091. `--doc` beside a target selector exits with a message naming the conflict (decision 1086). scripts/exit/s1097.sh fakes cargo, so it builds nothing.
