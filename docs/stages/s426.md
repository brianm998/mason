# s426: a skipped check is paid back when its task lands

Summary: After a task lands, every open debt it recorded (not only the deferred ones) is run once at the new base, so skipping per-task testing no longer leaves a debt with no payback.

**Cause.** `suites::after_landing` filtered open debts with `r.deferred`, so the owner's bulk `skip_test` debts (non-deferred) stayed open forever (78 skips, 30 `step:test` debts outstanding).

**Change.** The filter is gone; `pay` runs the skipped suite on the base tip and closes the debt when green, otherwise it stays open and logs why.

**Not changed.** Whether skipping is allowed (`allowed_actions`), and debts of tasks already landed (pay those with `POST /debts/{id}/run`).
