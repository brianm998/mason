# s48: Limits are for the machine and for work MASON starts for itself

Summary: no count caps the owner's tasks. The only strict limits are concurrent LLM sessions (`llm:claude`, default 10) and local compile CPU (a compile starts only while CPU use is below `compile_cpu_max`, default 50%). `max_open`, `per_week`, `max_steps` and the cooldown bound only work MASON starts for itself.
