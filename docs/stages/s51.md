# s51: A constant daemon port, and monitors that reconnect by themselves
Summary: masond keeps a constant loopback port (default 7423, configurable) and the CLI and both monitors re-read daemon.json and reconnect by themselves after a restart.

Task #23. `masond` listens on 127.0.0.1:7423 by default (`--port`, then `[daemon] port` in `daemon.toml`, override it; `--port 0` is a free port); a taken port is a loud exit 1; `daemon.json` stays the source of truth. The CLI re-reads it once on a refused connection; the SwiftUI and Compose monitors re-read it on failure (1, 2, 4, 8 s, then 10 s), watch it while connected, ping, detect a stall and resume from the last sequence number. Reasoning: `docs/decisions/0029-fixed-port-readings.md`; operation: `docs/self-hosting.md`, "The port".

Tests: `crates/daemon/tests/port.rs`; the reconnect tests in `MonitorCoreTests` (Swift) and `MonitorCoreTest` (Compose); exit test `bash scripts/exit/s51.sh`. Existing exit scripts and the test helper now pass `--port 0`.
