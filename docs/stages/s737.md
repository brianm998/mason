# s737: three remote tests were wrong, not the code

Summary: Three `remote::tests` failures are fixed in the tests: a leap-year date pair, a skip test that outlasted the run's 600 s limit, and a rust-cache check that matched a template comment.

**Cause.** 2026 is not a leap year, so Feb 28 to Mar 1 is one day (the test now uses 2028 for two days and 2026 for one). The skip test's 40-poll case skipped near 800 s, after the 600 s limit; it now skips from the fake clock at 30 s (queued) and 300 s (running). The swiftpm test matched `rust-cache` in a template comment; it now checks step lines only. No production code changed.
