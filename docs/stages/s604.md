# s604: exit-scripts runner names failing scripts in its last line

Summary: The exit-scripts runner now prints `FAILED scripts: <names>` as its last stdout line on failure, so a log tail names the failing script.

**Cause.** CI/exit-scripts (ubuntu-latest, 6) was red at 41dda8d8, but the supplied tail shows only s580's cargo output and its `skip: windows cross-check failed` echo. s580 masks that failure (`|| echo`) and exits 0, so the cc-rs/lib.exe error is noise. The `FAILED: <script>` line goes to stderr earlier in the log, outside the tail.

**Fix.** scripts/run-exit-scripts.sh collects failed scripts and prints `FAILED scripts: ...` last; exit status is unchanged. scripts/exit/s604.sh checks it.

**Held.** The runner is a protected gate (crates/daemon/src/protect.rs:32); that edit needs owner approval.

**Not verified.** The full shard 6 was not run, and the failing script at 41dda8d8 is not named.
