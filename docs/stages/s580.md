# s580: CI/windows built the daemon test support with unix-only nix

Summary: The daemon tests' orphan sweep is now compiled only on unix, with a no-op elsewhere, so the Windows `--all-targets` build no longer fails on the `nix` crate.

**Cause.** `crates/daemon/tests/support/mod.rs` used `nix` unconditionally, but `nix` is a `cfg(unix)` dependency, so every test target including `mod support;` failed with E0433 on Windows. The `policyd.rs` `Duration` import is already gated on macOS on develop.

**Fix.** The process table, scratch-root parser and `sweep_orphans` live in a `#[cfg(unix)]` module; non-unix gets an empty `sweep_orphans`.

**Tests.** `scripts/exit/s580.sh` builds the daemon tests and runs clippy, and checks the Windows target when installed.

**Not verified.** No Windows build was run here; other Windows-only errors in later targets are not ruled out.
