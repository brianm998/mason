# s1081: conformance expected waits for the step's view

Summary: The Rust conformance capturer no longer leaves its settle after 1.5 s of quiet; it waits for the step's view, with a 5 s quiet fallback that is logged.

## Cause
`settle()` left on a 1.5 s quiet period before the step's view arrived, so expected(k) captured the state after step k-1 (CI/monitor-swift, run 45361042086). Not confirmed from the log's stderr.

## Change
`should_leave` and `QUIET_WINDOW_MS` (5000) in crates/conformance/src/main.rs, with unit tests. Compare rule and files unchanged. Follow-up: MonitorTool's settle reads `lastSeq`, which also moves on events.
