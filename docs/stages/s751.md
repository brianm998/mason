# s751: a narrowed run keeps template cargo flags before the module filter (#764)

Summary: A narrowed run whose target group has a module filter now puts the filter at the end of the template's own `--` section, so the template's `--config` no longer reaches the test binary.

`scope::expand` (also used by `resume.rs`) splits a group at its first ` -- `: the cargo part goes at `{tests_for_change}`, the binary part is appended to the template's `--` tail, or starts one. Builds are unchanged.
