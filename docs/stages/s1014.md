# s1014: RemotePlacementTest lays the body out in a Column

Summary: RemotePlacementTest now composes RemotePlacementBody inside a Column, as the settings page does, so the project row no longer covers the global row's buttons.

## Cause

`RemotePlacementBody` emits its rows with no enclosing layout. In the page they sit in `Section`'s Column; in the test root they stacked at the top-left, and the project row covered the global "remote" button, so the click hit `project:favor-local`.

## Change

Test only: `RemotePlacementTest.kt` wraps the body in `Column`. No production code, assertion or expected value changes. See decision 1007.

## Tests

`gradle :app:test --tests 'mason.monitor.ui.RemotePlacementTest'` (scripts/exit/s1014.sh).
