# Stage 299: Offscreen editor tests and the owner's list of real checks

Summary: Both clients have an offscreen test that drives the pipeline editor's controls (add a step, connect it, edit a form field, undo) and compares the operations and the drawing with a stand-in draft; `docs/real-checks.md` lists, for every `scripts/exit/*-real.sh` (new `s299-real.sh` for the real Codex CLI included), what it costs and where to record the result, each prints a `RESULT sNN-real:` line, and CI builds the device sample app (build only).

## Built
- **Swift** (`Editor.swift`): the actions of the editor's controls (undo, redo, add a step, connect, set a field) moved into `EditorActions`, which the buttons, pickers and fields call and the test calls. No behaviour change. `EditorSnapshotTests.swift` renders `EditorPage` into an `NSHostingView` that is never in a window (`cacheDisplay`), drives the actions, checks the captured operations against a stand-in draft, and checks that the bitmap changes after each edit and returns to the first one after undo. No golden files, no timing, no XCUITest.
- **Compose**: `EditorSnapshotTest.kt` uses `runComposeUiTest` (added `compose.uiTest` to `app/build.gradle.kts`) and clicks the real controls (palette button, edge menu, form field with its Set button, Undo). The model's `sender` seam captures the commands, so no model change was needed.
- **`docs/real-checks.md`**: one entry per item (script or steps, cost, where to record), plus the older real scripts. `scripts/exit/s299-real.sh` is new: one `codex exec --json` call on a scratch repository; refuses without `MASON_REAL_APPROVED=yes` and `MASON_REAL_LIVE=yes`. Each existing `*-real.sh` now ends with a `RESULT sNN-real:` line.
- **CI**: jobs `device-sample-ios` (`swift build`) and `device-sample-android` (`gradle :app:assembleDebug`), build only.
- **`scripts/exit/s299.sh`**: runs both suites (skipped when swift or gradle is missing, or `MASON_SKIP_SWIFT` / `MASON_SKIP_COMPOSE`), checks the page lists every `*-real.sh` and names none that is missing, and that each ends with its RESULT line.
