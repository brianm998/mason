# s1222: bound the manual merge rounds of run_check

Summary: after 3 conflicted base folds in a row, run_check stops telling the agent to merge the base by hand and points to the landing queue.

## Cause

`basefold::note` told the agent to merge by hand on every conflicted check, with no count. With the base moving about 75 commits in 1.5 h, the agent never reached a full check round.

## Change

`basefold::record_fold` keeps a per-task `fold-conflicts.txt` (one line per conflicted fold, emptied by a clean or merged fold). `note_bounded` gives the old text below `MANUAL_MERGE_ROUNDS` (3) and a landing-queue hand-off from then on. `conflicts.txt` and `CONFLICT_ROUNDS` are untouched. See decision 1212.
