# s716: the changed-exit-scripts helper finds its selector from its own directory

Summary: scripts/run-changed-exit-scripts.sh now runs select-exit-scripts.sh from the helper's own directory and fails with `FAIL select-exit-scripts` when the selector errors, which fixes s249 on ubuntu-latest; s193 and s219 stay open.

**Cause (s249).** The helper ran `bash scripts/select-exit-scripts.sh` relative to the repository root. s249 runs the helper in a temporary repository without that file, so the selector's error was swallowed, the helper printed `PASS none` and exited 0, and s249's first check failed. Red since s669 added the selector call.

**Change.** Resolve the selector from `dirname "$0"`, capture its output, and fail loudly on a non-zero exit. Protected scripts are untouched.
