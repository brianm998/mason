# s1170: a landing push waits out a network outage

Summary: push_candidate waits and retries (up to the outage limit) when git cannot reach the remote (DNS, route, timeout), instead of failing the landing step.

## Cause

`push_candidate` in `crates/daemon/src/landing.rs` failed the landing at once on "Could not resolve hostname github.com"; the same task failed four times.

## Change

The push runs under `retry_outage`; unreachable-network errors are tagged as outages. Refusals still fail at once.
