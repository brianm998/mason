# s764: s636 honours MASON_EXIT_REPEAT

Summary: `scripts/exit/s636.sh` now reads `MASON_EXIT_REPEAT` (default 10) and has a weight, so the push run of `CI/exit-scripts` stays under the 900 s per-script limit.

Cause: s636 ran its cargo test 10 times, hard-coded, each waiting for the 60 s rate-limit window; every other repetition script reads `MASON_EXIT_REPEAT`, which ci.yml sets to 2 on push. It had no weights.txt entry either. Those files were listed as changed in every remote run, which selected s706, s722, s723, s729, s748 and s750 just because they mention `.mason/run.json`. No assertion or timeout changed; the nightly run still does 10.
