# s1221: an under-granted run waits for runner units

**Cause.** `wait_for_grant` (`crates/daemon/src/remote.rs`) waited for a bigger grant only when
this Mac was barred from running the run. A project without `fallback = "local"` got
`NotNeeded`, so a grant below `min_shards` ended as "no result (infrastructure)" and the agent
ran the check again.

**Change.** With no local fallback the run waits on GitHub for at least `min_shards` units,
then is split and pushed. The wait is before the attempt loop, so no attempt, environmental
failure or check round is spent. If the pool's limit is below what is needed, the error stays.

**Exit test.** `scripts/exit/s1221.sh`.
