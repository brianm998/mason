# s775: the joint-failure landing test no longer races its own window

Summary: `two_changes_that_merge_cleanly_and_do_not_build_together_do_not_land` now forms its batch by `max_size = 2` instead of a 2 s window, so a slow setup of the second task cannot land the first alone.

**Cause.** `crates/daemon/tests/it/landing_floor.rs:53` used `window = "2s"` with `max_size = 5`, so the batch formed only when the window closed (`crates/landing/src/plan.rs` `form_batch`). If creating the second task took longer than the window, `left` landed alone and the test timed out.

**Change.** The world uses `window = "20m"` and `max_size = 2`, as `landing_fast_tier.rs` does.

**Tests.** `scripts/exit/s775.sh` checks the world line. No timing assertions.
