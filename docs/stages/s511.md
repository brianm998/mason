# s511: alert when a task keeps hitting the same failing tests over several full runs

Summary: A develop step whose last three full run_check runs all end red on the same failing tests now raises a `needs_you` alert (and a task-page and needs-attention-count entry) naming the tests, how long, and whether they are red on develop; a green run clears it.

Record: `check_runs` (store migration 43), written by `TestChecks::run_scoped` for full runs only. Detector: `crates/daemon/src/circling.rs` (pure `detect`). Alert: `attention::alerts_now`. Views: `views.rs` (count and section), `http.rs` task JSON `circling`. Decision 0504. Exit test: `scripts/exit/s511.sh`.

Not verified: behaviour against a real agent's run_check on a live daemon; the clients' rendering of the alert.
