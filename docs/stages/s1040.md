# s1040: portable awk quotes in the exit-script lint

Summary: check-exit-portability.sh no longer uses gawk-only `\x27` escapes, so its refusals also fire under mawk on ubuntu-latest (s669).

## Cause

mawk does not understand `\x27`; see decision 1033. s546's failure text was not readable from here (no network, the log tail omits it), so s546 is unchanged and its cause is still unknown.

## Change

Quote passed via `awk -v q`, regexes built dynamically. New exit test `scripts/exit/s1040.sh`.
